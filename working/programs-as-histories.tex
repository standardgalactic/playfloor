\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Spherepop is a small programming language and interpreter whose evaluation model records an append-only history of events instead of overwriting program state. This monograph gives the formal theory behind that design and states, for each result, whether it is proved, proved on an explicit model, conditional on a cited result, exercised by executable examples, or open. The June 2026 edition, which developed a calculus of Pop, Refuse, Bind, and Collapse events over a finite option space, is the origin of the work and survives here as a corrected core: observation is a quotient of the history space by a collapse rule, the core fragment has proved type preservation, a progress result qualified by the availability of options, and equality of interpreted and compiled histories, and the bookkeeping of the option space is stated as a theorem for that calculus alone. The expanded edition reconsiders what this core can support. It replaces the claim that admissibility only contracts with a geometry of continuation spaces in which refinement, repair, and delegation can enlarge what a history permits, shows that observational sufficiency does not in general factor through the continuation structure, and separates validity, certification, and authorization as independent predicates in a protocol with a working record and an evidentiary record. It treats local certification in nested computations, where parts that are each admissible can fail to compose, with a presheaf of partial logs, a fully computed obstruction class, and a characterization of the coarsest sufficient boundary. It then treats abstraction and forgetting relative to what a system promises to support, verification cost, a development protocol with two reference kernels and a conformance ledger, and the attribution of responsibility when generative components propose changes. The lambda-calculus fragment, adjunctions between interpretation and observation, and a general reachability cohomology are not established and are listed as open problems.

\vspace{2.2em}
\noindent\textbf{Keywords:} event histories, operational semantics, admissibility types, quotient observation, continuation spaces, certification, nested composition, development protocol.

\chapter{State and History}
\label{ch:state}

\section{Motivation}

Introductory programming texts usually present a variable as a named location that holds a value. A program begins in an initial state, instructions modify that state, and the final state is the result.

\begin{lstlisting}
x = 5
y = x + 1
\end{lstlisting}

This description is adequate for many purposes, and it is the one most languages implement. It treats the present configuration as the unit of description and leaves the route by which the configuration was reached outside the model. The question pursued in this monograph is what a language looks like when the route is kept, and what follows mathematically from keeping it.

Keeping histories is not a new idea. Version control systems store the sequence of commits that produced a file tree, and event sourcing \cite{fowler} stores a log of events from which the current state of an application is computed by a fold. Process calculi \cite{hoare,milner} and event structures \cite{winskel} take occurrences, not states, as the primitive objects of a semantics. Spherepop adopts the same orientation at the level of a small language, and the contribution of the monograph lies in the specific constructions built on it: observation as a quotient, admissibility types, the relation between observation and continuation, and the separation of observation from authoritative commitment.

\section{What State Omits}

\begin{definition}[State Projection]
\label{def:degeneracy}
Let $E$ be a nonempty set of events and $\calH = \bigcup_{n\ge 0} E^n$ the set of finite histories. A \emph{state projection} onto a set $S$ is a function $\sigma:\calH\to S$. The \emph{degeneracy} of $s\in S$ is $D(s)=|\sigma^{-1}(s)|$.
\end{definition}

\begin{proposition}[Finite State Spaces Identify Histories]
\label{prop:state-illusion}
If $S$ is finite, every state projection $\sigma:\calH\to S$ is non-injective: there exist histories $H_1\neq H_2$ with $\sigma(H_1)=\sigma(H_2)$. Consequently $\sigma(H_1)=\sigma(H_2)$ does not imply $H_1=H_2$.
\end{proposition}

\begin{proof}
Because $E$ is nonempty, choosing any $e\in E$ gives infinitely many distinct histories $e^n$, so $\calH$ is infinite. A function from an infinite set to a finite set cannot be injective, so some fibre $\sigma^{-1}(s)$ has at least two elements.
\end{proof}

\begin{remark}
The statement is a pigeonhole fact and is elementary. It matters only for the vocabulary it fixes: a program that exposes only $\sigma(H)$ to its user has discarded, at the point of exposure, the distinctions among the histories in each fibre. Debuggers, audit logs, and provenance tools can be described as attempts to recover some of those distinctions after the fact. This is a description of what they do and is not a claim that this is all they do.
\end{remark}

\section{Consequences for Language Design}

Some familiar defects can be described in these terms. A data race is a case in which interleavings that differ as histories are conflated by the state that is finally observed, and a use-after-free is a case in which the observed state of a location does not distinguish a live object from a deallocated one. These are redescriptions, not explanations, and they do not show that a history-keeping language would be free of such defects. What retention of history provides is that the distinguishing information remains available when it is needed.

The design decision is accordingly modest: Spherepop stores the history and derives state from it on demand. The costs are real and are treated in later chapters. The history grows without bound unless it is compacted, the choice of observation rule becomes an explicit part of every program, and, as Part~\ref{part:cont} argues, retaining a history does not by itself settle which futures remain open to a system.

\chapter{The Spherepop World}
\label{ch:world}

\section{Events, Worlds, and Operators}

The calculus of this chapter and the following three is the original sequential Spherepop calculus. It is kept as stated because the reference implementation of Chapter~\ref{ch:codebase} realizes it. Part~\ref{part:protocol} introduces a second, distinct calculus, the development protocol, and Section~\ref{sec:terminology} fixes the relation between the two.

\begin{definition}[Event Alphabet]
Fix finite sets $\Sym$ of symbols, $\mathsf{Rsn}$ of refusal reasons, and $\mathsf{Rul}$ of collapse rules. The \emph{event alphabet} is
\[
\begin{gathered}E=\{\Pop(x),\ \Rfuse(x,r),\ \Bind(a,b),\ \Col(x,c)\mid\\ x,a,b\in\Sym,\ r\in\mathsf{Rsn},\ c\in\mathsf{Rul}\}\cup E_\lambda,\end{gathered}
\]
where $E_\lambda$ contains the lambda events $\mathrm{LamIntro}(x)$ and $\mathrm{Apply}(N)$ used in Chapter~\ref{ch:lambda}. The core fragment studied in Chapters~\ref{ch:types} through~\ref{ch:compiler} has $E_\lambda=\varnothing$, so that $E$ is finite.
\end{definition}

\begin{notation}
$\Omega_0\subseteq\Sym$ denotes the finite \emph{initial option space}. All option spaces $\Omega$ below satisfy $\Omega\subseteq\Omega_0$.
\end{notation}

\begin{definition}[Spherepop World and Event Application]
\label{def:world}
A \emph{world} is a pair $W=(H,\Omega)$ with $H\in\calH$ and $\Omega\subseteq\Omega_0$. The partial function $\mathrm{app}(e,W)$ applying an event to a world is
\begin{align*}
\mathrm{app}(\Pop(x),(H,\Omega)) &= (H\hconcat[\Pop(x)],\ \Omega\setminus\{x\}) \\ &\quad\text{if } x\in\Omega,\ \text{undefined otherwise},\\
\mathrm{app}(e,(H,\Omega)) &= (H\hconcat[e],\ \Omega) \\ &\quad\text{if } e \text{ is a Refuse, Bind, or Collapse event.}
\end{align*}
The corresponding \emph{operators} are written $P_x$, $R_{x,r}$, $B_{a,b}$, and $C_{x,c}$. A history $K=[e_1,\dots,e_n]$ is \emph{legal} from $W$ if $\mathrm{app}(e_n,\dots\mathrm{app}(e_1,W)\dots)$ is defined, and the result is written $\mathrm{run}(K,W)$. Lambda events leave $\Omega$ unchanged.
\end{definition}

The operator $P_x$ is the \emph{commitment} of the symbol $x$: it appends the event and removes $x$ from the option space. Refusal records that a symbol was found inadmissible and leaves the option space unchanged, so that it documents inadmissibility without foreclosing structural availability. Bind records a dependency between two symbols, and Collapse records an observation made under a collapse rule (Chapter~\ref{ch:quotient}).

\section{Bookkeeping Identities}

\begin{theorem}[Bookkeeping of History and Options]
\label{thm:conservation}
Let $e_1,\dots,e_n$ be legal from $W_0=(\varepsilon,\Omega_0)$ and write $W_t=(H_t,\Omega_t)$. Then for every $t$: (i) $|H_t|=t$; (ii) $\Omega_t\subseteq\Omega_{t-1}$, with $|\Omega_t|=|\Omega_{t-1}|-1$ when $e_t$ is a Pop event and $\Omega_t=\Omega_{t-1}$ otherwise; and (iii) $|\Omega_t|+\npop{H_t}=|\Omega_0|$, where $\npop{H}$ is the number of Pop events in $H$. In particular, if every event is a Pop then $|H_t|+|\Omega_t|=|\Omega_0|$.
\end{theorem}

\begin{proof}
Each application of $\mathrm{app}$ appends exactly one event, which gives (i). Only $\mathrm{app}(\Pop(x),\cdot)$ changes the option space, and it removes exactly the one element $x$, which is present by legality; this gives (ii). Part (iii) follows by induction on $t$: it holds at $t=0$, and each step either removes one element from $\Omega$ while adding one Pop to the count, or changes neither.
\end{proof}

\begin{corollary}[No Cycles]
\label{cor:irrev}
If $s<t$ then $W_s\neq W_t$ for any legal execution from $(\varepsilon,\Omega_0)$.
\end{corollary}

\begin{proof}
By Theorem~\ref{thm:conservation}(i), $|H_s|=s\ne t=|H_t|$.
\end{proof}

\begin{remark}
These identities are bookkeeping consequences of the definition of $\mathrm{app}$. They record that Pop is the only operation that changes the option space and that it changes it by one element. They are not a conservation law in the physical sense, and nothing below depends on that analogy. They are also specific to this calculus. Only part~(i) survives in a general setting where authoritative history is append-only; part~(ii) fails as soon as an operation can enlarge the set of feasible options, and Chapter~\ref{ch:cont} treats the corresponding generalization.
\end{remark}

\begin{implbox}{Implementation: \texttt{core/world.rs}}
The \texttt{World} structure holds the history and the option space and has no stored state field. Observable state is computed on demand from the history.
\begin{lstlisting}
pub struct World {
    pub options: OptionSpace,
    pub history: History,
}
\end{lstlisting}
\end{implbox}

\section{Terminology and the Development Protocol}
\label{sec:terminology}

The names Pop, Bind, and Collapse have a second, different meaning in the Spherepop Development Protocol of Part~\ref{part:protocol}, whose operation sequence follows Chapter~6 of \emph{Distinction Under Constraint} \cite{duc}. There POP opens a subordinate sphere within which a proposed transformation can be undertaken without modifying authoritative history, BIND attaches an authorization and a base version, and COLLAPSE commits a certified continuation to authoritative history. In the present chapter Pop consumes an option, Bind records a dependency, and Collapse seals an observation under a quotient rule. The two calculi are distinct semantic layers, and the correspondence between them, which is partial, is stated in Section~\ref{sec:correspondence}. To avoid ambiguity, the original operations are written $\Pop$, $\Bind$, $\Col$ and the protocol operations $\mathsf{POP}$, $\mathsf{BIND}$, $\mathsf{COLLAPSE}$ in capitals.

\chapter{The Algebra of Histories}
\label{ch:algebra}

\section{The History Monoid}

\begin{definition}[History and Concatenation]
A \emph{history} is a finite sequence $H=[e_1,\dots,e_n]$ of events. The empty history is $\varepsilon$. For $H_1=[e_1,\dots,e_m]$ and $H_2=[f_1,\dots,f_n]$, the concatenation is $H_1\hconcat H_2=[e_1,\dots,e_m,f_1,\dots,f_n]$.
\end{definition}

\begin{proposition}[Free Monoid]
$(\calH,\hconcat,\varepsilon)$ is the free monoid on $E$: for every monoid $(M,\cdot,1)$ and every function $g:E\to M$ there is a unique monoid homomorphism $\bar g:\calH\to M$ with $\bar g([e])=g(e)$.
\end{proposition}

\begin{proof}
Concatenation is associative with identity $\varepsilon$. Define $\bar g([e_1,\dots,e_n])=g(e_1)\cdots g(e_n)$, which is a homomorphism. Any homomorphism agreeing with $g$ on singletons is forced to take this value, since every history is the concatenation of its singletons.
\end{proof}

Unique factorization of a history into singleton events is a restatement of this fact, and it is what makes equality of histories a decidable criterion: two finite lists are equal exactly when they agree position by position.

\section{Legal Histories and the History Category}

\begin{definition}[History Category $\Hist$]
\label{def:hist-category}
Objects are option spaces $\Omega\subseteq\Omega_0$. A morphism $\Omega\to\Omega'$ is a history $H$ legal from $(\varepsilon,\Omega)$ whose run ends with option space $\Omega'$. Composition of $H_1:\Omega\to\Omega'$ and $H_2:\Omega'\to\Omega''$ is $H_1\hconcat H_2$, and the identity at $\Omega$ is $\varepsilon$.
\end{definition}

\begin{proposition}
$\Hist$ is a category. It is the free category on the directed graph whose vertices are option spaces and whose edges are the single-event transitions $\Omega\xrightarrow{e}\Omega'$ permitted by $\mathrm{app}$.
\end{proposition}

\begin{proof}
Composition is associative and unital because concatenation is. A morphism is a finite path in the transition graph, composition of paths is concatenation, and the identities are the empty paths. This is the standard description of a free category on a graph \cite{maclane}.
\end{proof}

\begin{remark}
No monoidal structure on $\Hist$ is claimed. Concatenation of two histories is sequential composition. A tensor product expressing parallel combination would require a notion of disjoint union of option spaces and a decision about interleaving, and raw concatenation does not supply either. Chapter~\ref{ch:distributed} treats concurrency through partially ordered histories instead.
\end{remark}

\begin{implbox}{Implementation: \texttt{core/history.rs}}
The history interface offers \texttt{append} and \texttt{meld} and no \texttt{remove} or \texttt{undo}, mirroring the freeness of the monoid. Equality of histories is structural list equality and is the identity criterion used in Chapter~\ref{ch:compiler}.
\begin{lstlisting}
pub fn append(&mut self, event: Event) {
    self.events.push(event);
}
pub fn meld(&mut self, other: &History) {
    self.events.extend(other.events.iter().cloned());
}
\end{lstlisting}
\end{implbox}

\chapter{Operational Semantics}
\label{ch:opsem}

\section{Transition Rules}

We write $(H,\Omega)\xrightarrow{\alpha}(H',\Omega')$ for a step labelled $\alpha$.
\[
\frac{x\in\Omega}{(H,\Omega)\xrightarrow{\mathrm{pop}(x)}(H\hconcat[\Pop(x)],\ \Omega\setminus\{x\})}\ \textsc{[Pop]}
\]
\[
\frac{}{(H,\Omega)\xrightarrow{\mathrm{refuse}(x,r)}(H\hconcat[\Rfuse(x,r)],\ \Omega)}\ \textsc{[Refuse]}
\]
\[
\frac{}{(H,\Omega)\xrightarrow{\mathrm{bind}(a,b)}(H\hconcat[\Bind(a,b)],\ \Omega)}\ \textsc{[Bind]}
\]
\[
\frac{}{(H,\Omega)\xrightarrow{\mathrm{collapse}(x,c)}(H\hconcat[\Col(x,c)],\ \Omega)}\ \textsc{[Collapse]}
\]
The rules agree with $\mathrm{app}$ of Definition~\ref{def:world}. \textsc{[Refuse]} has no premise, so any symbol may be refused. \textsc{[Collapse]} has no premise at the level of worlds either. The requirement that a collapsed term carry an admissibility certificate is a static condition enforced by the type system of Chapter~\ref{ch:types}, so an untyped execution may collapse anything.

\section{The Historical Refusal Set}

\begin{definition}[Historical Refusal Set and Unrefused Symbols]
\label{def:admissible-futures}
For a history $H$, let $R(H)=\{x\mid \exists r.\ \Rfuse(x,r)\in H\}$ and $\calA^{\mathrm{hist}}(H)=\Omega_0\setminus R(H)$.
\end{definition}

\begin{proposition}[Monotonicity of the Refusal Set]
\label{def:admissibility-contraction}
For every event $e$, $R(H)\subseteq R(H\hconcat[e])$, with equality unless $e=\Rfuse(x,r)$ for some $x\notin R(H)$. Hence $\calA^{\mathrm{hist}}(H\hconcat[e])\subseteq\calA^{\mathrm{hist}}(H)$.
\end{proposition}

\begin{proof}
Appending an event adds at most one symbol to $R$, and only a Refuse event adds one.
\end{proof}

\begin{remark}[Refusal Does Not Restrict Popping]
\label{rem:refusal-pop}
The premise of \textsc{[Pop]} is $x\in\Omega$ only. A symbol that has been refused therefore remains available to Pop: from $(\varepsilon,\Omega_0)$ the history $[\Rfuse(x,r),\Pop(x)]$ is legal. The set $\calA^{\mathrm{hist}}(H)$ is a recorded quantity that types and collapse rules may consult, and it does not by itself restrict execution. A variant semantics with premise $x\in\Omega\setminus R(H)$ would make refusal operationally binding, and Theorem~\ref{thm:conservation} holds for that variant unchanged, because it only restricts which Pop events are legal. The results of this monograph are stated for the semantics as given. The variant also has a conceptual cost, since it makes every refusal permanently exclusionary, and Chapter~\ref{ch:cont} argues that permanent exclusion is the wrong default.
\end{remark}

\begin{remark}
Pop contracts the structural option space $\Omega$ while Refuse contracts the recorded set $\calA^{\mathrm{hist}}(H)$ and leaves $\Omega$ alone. Two histories may therefore end with the same option space and different refusal sets, which is the sense in which they are structurally equivalent and semantically distinguished.
\end{remark}

\chapter{From Sets to Certificates}
\label{ch:certs}

\section{Motivation}

The standard reading of a type is a set of admissible values. In a setting where the history is the stored object, a type can also be read as a record of the manner in which a term was produced. Two terms with the same underlying value may have been produced by different routes, and a record of the route can be part of the type. This reading is related to the proof-theoretic view of types as propositions \cite{martinlof}, with the difference that the certificate here concerns the production of a term and not a proposition about its value.

\begin{definition}[Spherepop Types]
\label{def:types}
\begin{align*}
T ::= \;& \mathrm{Unit}\;\mid\;\mathrm{Never}\;\mid\;X\;\mid\;\Pi(x:T_1).T_2\;\mid\;\Adm{T}\\ &\mid\;\Refused{T}{r}\;\mid\;\Collapsed{T}{c}\;\mid\;\mathrm{Process}(T_1\yields T_2)
\end{align*}
The function type $T_1\to T_2$ abbreviates $\Pi(\_:T_1).T_2$.
\end{definition}

The three distinctive types carry a certificate in addition to an inner type. A term of type $\Adm{T}$ was produced by a commitment. A term of type $\Refused{T}{r}$ was encountered and found inadmissible for reason $r$, and the reason is part of the type, so two terms refused for different reasons have different types. A term of type $\Collapsed{T}{c}$ is an admissible term observed under rule $c$, with the rule recorded in the type.

\begin{remark}[What $\Adm{T}$ Certifies]
\label{rem:adm-scope}
In the original calculus the constructor $\Adm{T}$ certifies one thing: the term was produced by a commitment operation, that is, by Pop. It does not certify that the committed transformation is correct, that evidence supports it, or that any agent was authorized to perform it. Those are separate questions. Part~\ref{part:cert} distinguishes validity, certification, and authorization as independent predicates, and a type system for the development protocol must not allow an ordinary typing derivation to become a certificate merely because Pop was applied. In the calculus of this part, $\Adm{T}$ is a marker of structural commitment and is read in no stronger sense.
\end{remark}

\chapter{The Admissibility Type System}
\label{ch:types}

\section{Typing Rules}

We write $\Gamma\vdash t:T$ for the typing judgement. The system is syntax-directed: each term form has exactly one typing rule, and there is no subsumption.
\[
\frac{\Gamma\vdash t:T}{\Gamma\vdash\mathrm{pop}(t):\Adm{T}}\ \textsc{[T-Pop]}
\]
\[
\frac{\Gamma\vdash t:T\quad r\in\mathsf{Rsn}}{\Gamma\vdash\mathrm{refuse}(t,r):\Refused{T}{r}}\ \textsc{[T-Refuse]}
\]
\[
\frac{\Gamma\vdash t:\Adm{T}\quad c\in\mathsf{Rul}}{\Gamma\vdash\mathrm{collapse}(t,c):\Collapsed{T}{c}}\ \textsc{[T-Collapse]}
\]
\[
\frac{\Gamma\vdash a:T_1\quad\Gamma\vdash b:T_2}{\Gamma\vdash\mathrm{bind}(a,b):\mathrm{Process}(T_1\yields T_2)}\ \textsc{[T-Bind]}
\]
\[
\frac{\Gamma\vdash t_1:T_1\quad\Gamma\vdash t_2:T_2}{\Gamma\vdash t_1;t_2:T_2}\ \textsc{[T-Seq]}
\]
\[
\frac{(x:T)\in\Gamma}{\Gamma\vdash x:T}\ \textsc{[T-Var]}
\]
\[
\frac{\Gamma,x:T_1\vdash b:T_2}{\Gamma\vdash\lambda x{:}T_1.b:\Pi(x{:}T_1).T_2}\ \textsc{[T-Lam]}
\]
\[
\frac{\Gamma\vdash f:\Pi(x{:}T_1).T_2\quad\Gamma\vdash a:T_1}{\Gamma\vdash f\,a:T_2[x:=a]}\ \textsc{[T-App]}
\]
The rules for unbound variables depend on the world assumption and are given in Chapter~\ref{ch:worlds}. Collapse requires an admissibility certificate: a term whose type is not $\Adm{\cdot}$ cannot be collapsed, and this is a type error and not a run-time exception.

\begin{theorem}[Collapse Soundness]
\label{thm:collapse-soundness}
If $\Gamma\vdash\mathrm{collapse}(t,c):T$ then $\Gamma\vdash t:\Adm{T'}$ for some $T'$ and $T=\Collapsed{T'}{c}$.
\end{theorem}

\begin{proof}
The system is syntax-directed and \textsc{[T-Collapse]} is the only rule whose conclusion has the form $\mathrm{collapse}(t,c)$. Inversion gives the premise and the shape of $T$.
\end{proof}

\section{The Core Fragment}
\label{sec:core}

The lambda fragment is treated in Chapter~\ref{ch:lambda}, and the metatheory of closures is not developed in this monograph. This section makes the statements of preservation and progress precise for the fragment in which they can be proved.

\begin{definition}[Core Terms, Values, and Evaluation]
Core terms are
\[
t::=\mathrm{pop}(x)\mid\mathrm{refuse}(x,r)\mid\mathrm{bind}(a,b)\mid\mathrm{collapse}(t,c)\mid t;t,
\]
with $x,a,b\in\Sym$. Values are $\mathrm{adm}(x)$, $\mathrm{ref}(x,r)$, $\mathrm{bnd}(a,b)$, and $\mathrm{col}(x,c)$, typed by $\mathrm{adm}(x):\Adm{\mathrm{Unit}}$, $\mathrm{ref}(x,r):\Refused{\mathrm{Unit}}{r}$, $\mathrm{bnd}(a,b):\mathrm{Process}(\mathrm{Unit}\yields\mathrm{Unit})$, and $\mathrm{col}(x,c):\Collapsed{\mathrm{Unit}}{c}$, provided the symbols are declared with type $\mathrm{Unit}$ in $\Gamma$. The evaluation function $\eval(t,W)$ returns either a pair $(v,W')$ or $\blocked(x)$:
\begin{align*}
\eval(\mathrm{pop}(x),W)&=(\mathrm{adm}(x),P_xW)\ \text{ if }x\in\Omega_W,\\ &\qquad\blocked(x)\text{ otherwise},\\
\eval(\mathrm{refuse}(x,r),W)&=(\mathrm{ref}(x,r),R_{x,r}W),\\
\eval(\mathrm{bind}(a,b),W)&=(\mathrm{bnd}(a,b),B_{a,b}W),\\
\eval(\mathrm{collapse}(t,c),W)&=(\mathrm{col}(x,c),C_{x,c}W')\\ &\qquad\text{if }\eval(t,W)=(\mathrm{adm}(x),W'),\\ &\qquad\text{and propagates }\blocked,\\
\eval(t_1;t_2,W)&=\eval(t_2,W_1)\\ &\qquad\text{if }\eval(t_1,W)=(v_1,W_1),\\ &\qquad\text{and propagates }\blocked.
\end{align*}
In the clause for collapse, if $t$ is well typed with type $\Adm(T)$ and $\eval(t,W)$ succeeds, its value has the form $\mathrm{adm}(x)$; evaluation can still be blocked when the option consumed by $t$ is unavailable. A type of the form $\Adm(T)$ anticipates commitment before execution, and only a successful evaluation yields a value that certifies that the commitment occurred.
\end{definition}

\begin{theorem}[Type Preservation for the Core Fragment]
\label{thm:preservation}
If $\Gamma\vdash t:T$ with all symbols of $t$ declared $\mathrm{Unit}$ in $\Gamma$, and $\eval(t,W)=(v,W')$, then $\Gamma\vdash v:T$.
\end{theorem}

\begin{proof}
By induction on $t$. For $\mathrm{pop}(x)$, \textsc{[T-Pop]} gives $T=\Adm{\mathrm{Unit}}$ and the value $\mathrm{adm}(x)$ has this type. The cases $\mathrm{refuse}$ and $\mathrm{bind}$ are identical. For $\mathrm{collapse}(t_1,c)$, inversion gives $\Gamma\vdash t_1:\Adm{T_1}$ and $T=\Collapsed{T_1}{c}$. By the induction hypothesis the value of $t_1$ has type $\Adm{T_1}$. The only values with a type of the form $\Adm{\cdot}$ are the $\mathrm{adm}(x)$, and for these $T_1=\mathrm{Unit}$, so the result $\mathrm{col}(x,c)$ has type $\Collapsed{\mathrm{Unit}}{c}=T$. For $t_1;t_2$ the claim is the induction hypothesis for $t_2$.
\end{proof}

\begin{theorem}[Progress up to Availability]
\label{thm:progress}
If $\Gamma\vdash t:T$ with all symbols declared $\mathrm{Unit}$, then for every world $W$, $\eval(t,W)$ is defined and is either a pair $(v,W')$ with $v$ a value or $\blocked(x)$ for a symbol $x$ that is absent from the option space at the point where the corresponding $\mathrm{pop}(x)$ is evaluated.
\end{theorem}

\begin{proof}
By induction on $t$. Each clause of $\eval$ is total on the term forms it covers, and the only clause that can fail to produce a pair is $\mathrm{pop}(x)$ with $x\notin\Omega_W$. Typing guarantees that the argument of $\mathrm{collapse}$ evaluates to some $\mathrm{adm}(x)$ whenever it evaluates to a value. Evaluation terminates because the fragment has no recursion.
\end{proof}

\begin{remark}
The unqualified form of progress, that a well-typed term is a value or can step, is false for this fragment: $\mathrm{pop}(x)$ is well-typed in any context declaring $x$ and is blocked in a world where $x$ has been consumed. This is a genuine gap between the type system and the semantics. The type system does not track the option space, so \textsc{[T-Pop]} accepts terms that the semantics cannot execute. Chapter~\ref{ch:future} describes a resource-indexed judgement $\Gamma;\Omega\vdash t:T\dashv\Omega'$ in which Pop consumes an affine resource. With such a judgement the blocked case would be excluded statically, and this is left as future work.
\end{remark}

\begin{remark}[Scope]
Substitution, canonical forms, preservation, and progress for the lambda fragment require a term-level reduction relation with closures and a treatment of variable binding. These are not established here, and Preservation and Progress are claimed only for the core fragment above. The relation of the typing discipline to the Wright--Felleisen method \cite{wf} is that of intention: the proofs above follow the same shape on a fragment small enough to be complete.
\end{remark}

\chapter{Open Worlds and Closed Worlds}
\label{ch:worlds}

\section{An Implementation Conflict}

During implementation of the type checker a conflict appeared. The interpreter treated a free variable as a symbolic atom, so an unbound $x$ evaluated to a symbol value, while the first version of the type checker rejected unbound variables. Programs that evaluated correctly failed type checking. The immediate repair was to give free variables the type $\mathrm{Unit}$. The repair raises a question that deserves a precise answer: which behavior is correct? Both are, under different assumptions about the boundary of the world, in the sense of the closed-world and open-world assumptions of Reiter \cite{reiter}.

\section{Definitions}

\[
\frac{x\notin\Gamma\quad\Gamma\ \text{is open-world}}{\Gamma\vdash x:\mathrm{Unit}}\ \textsc{[T-Var-Open]}
\]
\[
\frac{x\notin\Gamma\quad\Gamma\ \text{is closed-world}}{\text{no typing derivation for }x}\ \textsc{[T-Var-Closed]}
\]

A \emph{closed-world} context treats the absence of a declaration as the absence of the object, so an undeclared variable has no type, and in particular the absence of a derivation does not mean that the bottom type is derivable. An \emph{open-world} context treats an undeclared symbol as undecided possibility and assigns it the type $\mathrm{Unit}$.

\begin{definition}[Provable Judgements]
For a context $\Gamma$, $\mathrm{Provable}(\Gamma)=\{(t,T)\mid\Gamma\vdash t:T\}$.
\end{definition}

\begin{proposition}[Monotonicity in the World Assumption]
\label{prop:ow-monotone}
Let $\Gamma_o$ be the open-world context with the same declarations as the closed-world context $\Gamma_c$. Then $\mathrm{Provable}(\Gamma_c)\subseteq\mathrm{Provable}(\Gamma_o)$, and the inclusion can be strict.
\end{proposition}

\begin{proof}
Every derivation in $\Gamma_c$ uses \textsc{[T-Var]} for variables, and the same instances are available in $\Gamma_o$, which differs only by the additional rule \textsc{[T-Var-Open]}. The inclusion is strict because a term with an undeclared variable, such as $\mathrm{pop}(y)$, has a type only in $\Gamma_o$.
\end{proof}

\begin{implbox}{Implementation: \texttt{types/checker.rs}}
\begin{lstlisting}
pub enum TypeMode {
    ClosedWorld,  // unknown variable is a type error
    OpenWorld,    // unknown variable has type Unit
}
pub struct Context {
    bindings: HashMap<String, Type>,
    pub mode: TypeMode,
}
\end{lstlisting}
The mode is preserved through \texttt{extend}, so a closed-world context does not become open-world during a derivation.
\end{implbox}

\chapter{Observable State as a Quotient of History}
\label{ch:quotient}

\section{Collapse Rules}

The first design of the collapse event recorded only the symbol that had been collapsed. That record is insufficient, because it does not say what the observation reveals: the same history examined under different frameworks yields different observable states, and a collapse without a rule leaves the notion of visibility unspecified. A collapse event therefore carries a rule.

\begin{definition}[Collapse Rule, Image, and Quotient]
\label{def:collapse-rule}
A \emph{collapse rule} is a function $c:\calH\to O_c$ into an \emph{observational codomain} $O_c$. Its \emph{image} is $c(\calH)\subseteq O_c$. Two histories are \emph{observationally equivalent under $c$}, written $H_1\sim_c H_2$, if $c(H_1)=c(H_2)$. The \emph{observable state space} is the quotient $\calH/{\sim_c}$, which is in bijection with the image $c(\calH)$ and in general with a proper subset of the codomain. We write $[H]_c$ for the class of $H$ and $q_c:\calH\to\calH/{\sim_c}$ for the quotient map.
\end{definition}

\begin{remark}
The distinction among codomain, image, and quotient matters when counting. The number of observable states under $c$ is $|c(\calH)|$ and not $|O_c|$. An observable state is an equivalence class of histories, and two globally distinct histories can be indistinguishable under a rule. This is a feature: the rule specifies which distinctions are relevant to a given question.
\end{remark}

\section{Four Canonical Rules}

For an event $e$ let $\mathrm{sym}(e)$ be its principal symbol: $x$ for $\Pop(x)$, $\Rfuse(x,r)$, and $\Col(x,c)$, and $a$ for $\Bind(a,b)$.

\begin{definition}[Canonical Rules]
The \emph{Identity} rule is $c_I(H)=H$. The \emph{LastWrite} rule is $c_{LW}(H)=\{x\mid\Pop(x)\in H$ and no $\Rfuse(x,r)$ occurs after the last occurrence of $\Pop(x)\}$. The \emph{Accumulate} rule is $c_{\mathrm{acc}}(H)(x)=|\{i\mid e_i=\Pop(x)\}|$. For a label prefix $L$, the \emph{Projection} rule is $\pi_L(H)=[e_i\in H\mid\mathrm{sym}(e_i)\text{ starts with }L]$, the subsequence of events whose principal symbol begins with $L$.
\end{definition}

\begin{remark}
In legal histories each symbol is popped at most once, since Pop removes it from the option space, so on legal histories $c_{\mathrm{acc}}$ takes values in $\{0,1\}$. It then differs from $c_{LW}$ only through refusals, which $c_{\mathrm{acc}}$ ignores. The two rules separate on arbitrary histories and on legal histories containing refusals, and would separate more sharply in a variant calculus that allows repeated commitment.
\end{remark}

\section{Refinement}

\begin{definition}[Refinement Preorder]
For rules $c_1,c_2$, write $c_1\preceq c_2$ ($c_1$ is \emph{finer}) if ${\sim_{c_1}}\subseteq{\sim_{c_2}}$, that is, $H_1\sim_{c_1}H_2$ implies $H_1\sim_{c_2}H_2$.
\end{definition}

The relation $\preceq$ is reflexive and transitive, so it is a preorder on rules and not in general a partial order: two rules with the same partition of $\calH$ are mutually related. It becomes a partial order on partitions, that is, on rules taken up to the identification of rules inducing the same equivalence relation. The identity rule $c_I$ is finest, and the rule $c_\top$ sending every history to one point is coarsest.

\begin{proposition}[Lattice of Observations]
\label{prop:lattice}
The partitions of $\calH$ ordered by refinement form a complete lattice. The greatest lower bound of a family is the intersection of the equivalence relations, and the least upper bound is the equivalence relation generated by their union.
\end{proposition}

\begin{proof}
The family of equivalence relations on a set is closed under arbitrary intersection, and the intersection is the largest relation contained in each member, which is the greatest lower bound for the order ``finer''. The smallest equivalence relation containing a union of equivalence relations is its reflexive, symmetric, transitive closure, which is the least upper bound. A poset with all meets and joins is a complete lattice.
\end{proof}

\begin{example}[Incomparable Rules]
\label{ex:incomparable}
Consider legal histories over $\Sym\supseteq\{x\}$. The histories $[\Pop(x)]$ and $[\Pop(x),\Rfuse(x,r)]$ have the same value under $c_{\mathrm{acc}}$ and different values under $c_{LW}$, so $c_{LW}\not\succeq c_{\mathrm{acc}}$. The histories $[\Pop(x),\Rfuse(x,r)]$ and $[\Rfuse(x,r)]$ have the same value under $c_{LW}$ (the empty set) and different values under $c_{\mathrm{acc}}$, so $c_{\mathrm{acc}}\not\succeq c_{LW}$. Hence $c_{LW}$ and $c_{\mathrm{acc}}$ are incomparable. The Identity rule is finer than every rule.
\end{example}

\begin{implbox}{Implementation: \texttt{core/observable.rs}}
\begin{lstlisting}
pub fn derive(history: &History, rule: &CollapseRule)
    -> ObservableState
pub fn equivalent(h1: &History, h2: &History,
                  rule: &CollapseRule) -> bool {
    Self::derive(h1, rule) == Self::derive(h2, rule)
}
\end{lstlisting}
Observable state is derived on each call and is never stored in the world.
\end{implbox}

\chapter{Compositional Rules and Factorization}
\label{ch:compositional}

\section{Compositionality}

A collapse rule may be applied to a long history, or to the pieces of it. Whether the observation of the whole is determined by the observations of the pieces depends on the rule.

\begin{definition}[Compositional Rule]
A rule $c$ is \emph{compositional} if $\sim_c$ is a congruence of the history monoid: $H_1\sim_cH_2$ implies $K\hconcat H_1\hconcat L\sim_cK\hconcat H_2\hconcat L$ for all histories $K,L$.
\end{definition}

\begin{proposition}[Characterization]
\label{prop:congruence}
A rule $c$ is compositional if and only if the set $\calH/{\sim_c}$ carries a monoid structure making $q_c$ a monoid homomorphism. The structure is then unique, given by $[H_1]_c\cdot[H_2]_c=[H_1\hconcat H_2]_c$.
\end{proposition}

\begin{proof}
If $\sim_c$ is a congruence the displayed product is well defined, associative, and has unit $[\varepsilon]_c$, and $q_c$ is a homomorphism by construction. Conversely, if a monoid structure makes $q_c$ a homomorphism, then $[K\hconcat H_i\hconcat L]_c=[K]_c[H_i]_c[L]_c$, so equal classes for $H_1,H_2$ give equal classes for the extensions. Uniqueness holds because $q_c$ is surjective.
\end{proof}

\begin{proposition}[Canonical Rules]
\label{prop:canonical-compositional}
The rules $c_I$, $c_{\mathrm{acc}}$, and $\pi_L$ are compositional. The rule $c_{LW}$ is not compositional, even when restricted to legal histories. Legal histories from a fixed initial option space are not closed under concatenation (the history $[\Pop(x)]$ is legal and its concatenation with itself is not), so for legal histories noncompositionality means a failure of contextual substitutability under jointly legal extensions, which is the analogue on composable legal paths of the monoid congruence on arbitrary histories.
\end{proposition}

\begin{proof}
$c_I$ is injective, so its equivalence is the diagonal. $c_{\mathrm{acc}}$ is a homomorphism into the monoid of finitely supported count maps under pointwise addition, and $\pi_L$ is a homomorphism into the free monoid on the filtered events; the kernel of a homomorphism is a congruence. For $c_{LW}$ take $H_1=[\Rfuse(x,r)]$ and $H_2=\varepsilon$, which satisfy $c_{LW}(H_1)=c_{LW}(H_2)=\varnothing$. With $K=[\Pop(x)]$, $c_{LW}(K\hconcat H_1)=\varnothing$ while $c_{LW}(K\hconcat H_2)=\{x\}$. All four histories are legal from any option space containing $x$.
\end{proof}

The failure for LastWrite is the formal content of the observation that a later segment can alter, retroactively, the observable state of an earlier one.

\begin{definition}[Collapse Functor]
\label{def:collapse-functor}
For a compositional rule $c$ let $\mathbf B(O_c)$ be the one-object category with morphisms the elements of the monoid $\calH/{\sim_c}$. The \emph{collapse functor} $F_c:\Hist\to\mathbf B(O_c)$ sends every object to the single object and a morphism $H:\Omega\to\Omega'$ to $[H]_c$.
\end{definition}

\begin{theorem}[Functoriality of Compositional Collapse]
\label{thm:functor}
If $c$ is compositional, $F_c$ is a functor. In particular $F_c(H_1\hconcat H_2)=F_c(H_1)\cdot F_c(H_2)$, with composition of morphisms taken in the order in which histories are concatenated.
\end{theorem}

\begin{proof}
$F_c(\varepsilon)=[\varepsilon]_c$ is the unit. For composable $H_1:\Omega\to\Omega'$ and $H_2:\Omega'\to\Omega''$, the composite in $\Hist$ is $H_1\hconcat H_2$, and $[H_1\hconcat H_2]_c=[H_1]_c\cdot[H_2]_c$ by Proposition~\ref{prop:congruence}.
\end{proof}

\begin{remark}
The rule $c_{LW}$ shows that the hypothesis of the theorem cannot be dropped: classes of histories cannot be composed when the equivalence is not a congruence. The category of observable transitions in earlier presentations is replaced here by a one-object category whose morphisms are classes, which is the object the statement can actually be proved for.
\end{remark}

\section{Factorization and Universal Property}

\begin{theorem}[Factorization of Coarser Rules]
\label{thm:factorization}
Let $c_1,c_2$ be rules. Then $c_1\preceq c_2$ if and only if there is a function $f:c_1(\calH)\to O_{c_2}$ with $c_2=f\circ c_1$, and $f$ is then unique. If $c_1,c_2$ are compositional, $f$ is a monoid homomorphism between the induced monoids.
\end{theorem}

\begin{proof}
If $c_1\preceq c_2$, define $f(c_1(H))=c_2(H)$; this is well defined since $c_1(H)=c_1(H')$ implies $c_2(H)=c_2(H')$. Uniqueness follows from surjectivity of $c_1$ onto its image. Conversely, if $c_2=f\circ c_1$ then $c_1(H)=c_1(H')$ implies $c_2(H)=c_2(H')$. For compositional rules, $f([H]_{c_1}[H']_{c_1})=f([H\hconcat H']_{c_1})=c_2(H\hconcat H')=c_2(H)\cdot c_2(H')$ in the induced structure.
\end{proof}

\begin{corollary}[Observational Pipelines]
For rules $c_1$ and $f:c_1(\calH)\to O$, the composed rule $f\circ c_1$ is coarser than $c_1$, and every rule coarser than $c_1$ arises in this way. A pipeline of observations from finer to coarser is therefore exactly a factorization.
\end{corollary}

\begin{theorem}[Universal Property of the Quotient]
\label{thm:universal-collapse}
If $g:\calH\to X$ is constant on $\sim_c$-classes then there is a unique $\bar g:\calH/{\sim_c}\to X$ with $g=\bar g\circ q_c$.
\end{theorem}

\begin{proof}
Set $\bar g([H]_c)=g(H)$, well defined by hypothesis. Any $\bar g$ with $g=\bar g\circ q_c$ must take this value.
\end{proof}

The results of this section are elementary. They are stated because they are the precise forms in which categorical language earns its place here: the functor condition identifies compositional rules, and factorization identifies coarsening with the existence of a map between codomains.

\section{Canonical Representatives}

A rule determines a class of histories, and one may ask for a canonical representative of each class that respects composition.

\begin{proposition}[Homomorphic Sections]
\label{prop:section}
For $c_I$ and $\pi_L$ there is a monoid homomorphism $s$ with $q_c\circ s=\mathrm{id}$ on the image. For $c_{\mathrm{acc}}$ with at least two symbols there is none.
\end{proposition}

\begin{proof}
For $c_I$ take $s=\mathrm{id}$. For $\pi_L$ the image is the free monoid on the events with principal symbol beginning with $L$, and the inclusion is a section. For $c_{\mathrm{acc}}$ suppose $s$ were a homomorphic section and let $x\neq y$ be symbols, $1_x,1_y$ the corresponding unit count maps. The words $w_x=s(1_x)$ and $w_y=s(1_y)$ satisfy $w_xw_y=s(1_x+1_y)=w_yw_x$, so they are powers of a common word $u$ in the free monoid. Each contains exactly one $\Pop(x)$, respectively $\Pop(y)$, hence both are equal to $u$ with $u$ containing both; but $c_{\mathrm{acc}}(w_x)=1_x$ forbids $\Pop(y)$ in $w_x$. Contradiction.
\end{proof}

Sections exist set-theoretically for every rule; what fails for $c_{\mathrm{acc}}$ is the existence of one compatible with composition, since the target monoid is commutative and the history monoid is free.

\chapter{Limits of Observation}
\label{ch:limits}

\section{An Objection}

One may object that Spherepop relocates the state illusion instead of resolving it. Every output of a program is a collapse, a value derived by applying a rule to a history, and the programmer sees the collapsed value and not the history. The objection is correct as far as it goes, and this chapter states precisely what is and is not eliminated.

\section{Limits}

\begin{theorem}[No Direct Observation by Finite Spaces]
\label{thm:no-direct-obs}
If $|O|<|\calH|$, that is, if $O$ is finite, every observation map $\phi:\calH\to O$ is non-injective.
\end{theorem}

\begin{proof}
$\calH$ is infinite, so a map into a finite set cannot be injective.
\end{proof}

This repeats Proposition~\ref{prop:state-illusion} and is no deeper. It is useful for the quantitative version below, and it does not apply to observation spaces that are themselves infinite: the Identity rule is injective.

\begin{proposition}[Bounded Histories Require Bits]
\label{prop:bits}
Let $|E|=m\ge2$ and let $\calH_{\le n}$ be the set of histories of length at most $n$. Any observation map injective on $\calH_{\le n}$ has $|O|\ge(m^{n+1}-1)/(m-1)\ge m^n$, so that $\log_2|O|\ge n\log_2m$. If $|O|$ is finite then some fibre of any observation map is infinite.
\end{proposition}

\begin{proof}
$|\calH_{\le n}|=\sum_{k=0}^nm^k$, and an injective map needs at least that many values. If $|O|$ is finite while $\calH$ is infinite, some fibre is infinite by pigeonhole.
\end{proof}

\section{Erasure and Illusion}

\begin{definition}[State Erasure and State Illusion]
A system suffers \emph{state erasure} if it discards a history $H$ after computing $\sigma(H)$. It presents a \emph{state illusion} if its users observe only $\sigma(H)$ and not $H$, with $\sigma$ non-injective.
\end{definition}

Erasure is a choice made by a system and illusion is a property of an observation map. A system that retains $H$ for the lifetime of the world eliminates erasure while accepting that its ordinary observations are non-injective. In the implementation the history is kept in \texttt{world.history}, at a cost in memory linear in the number of events. Retention is a design property of the implementation and not a theorem. Part~\ref{part:memory} considers when retention is unnecessary.

\begin{proposition}[Disambiguation by Refinement]
\label{prop:disambiguation}
If $H_1\sim_cH_2$ and $H_1\ne H_2$, there is a rule $c'\preceq c$ with $c'(H_1)\ne c'(H_2)$. The rule can be chosen to differ from $c$ in a single class: $c'$ splits $[H_1]_c$ into $\{H_1\}$ and $[H_1]_c\setminus\{H_1\}$ and agrees with $c$ elsewhere. The Identity rule always disambiguates.
\end{proposition}

\begin{proof}
The partition of $c'$ refines that of $c$, so $c'\preceq c$, and $H_1,H_2$ lie in different classes. $c_I\preceq c$ separates any two distinct histories.
\end{proof}

A system that retains histories can apply the finer rule later, and a system that has erased them cannot. This is the engineering content of retention.

\section{Entropy of Fibres}

At least one fibre of a rule with finite codomain is infinite, while others may be finite or empty, so the entropy of a fibre is defined on bounded histories.

\begin{definition}[Bounded Observational Entropy]
\label{def:obs-entropy}
For a rule $c$, an integer $n$, and $H\in\calH_{\le n}$, let $S^{(n)}_c(H)=\log|[H]_c\cap\calH_{\le n}|$, which is finite when $E$ is finite.
\end{definition}

\begin{theorem}[Monotonicity Under Refinement]
\label{thm:entropy-monotone}
If $c_1\preceq c_2$ then $S^{(n)}_{c_1}(H)\le S^{(n)}_{c_2}(H)$ for all $n$ and $H\in\calH_{\le n}$.
\end{theorem}

\begin{proof}
$[H]_{c_1}\subseteq[H]_{c_2}$, so the finite sets satisfy the same inclusion after intersecting with $\calH_{\le n}$.
\end{proof}

For a map $\pi:X\to M$ the CLIO framework defines representational entropy $S_\pi(m)=\log\mathrm{Vol}(\pi^{-1}(m))$ \cite{clio}, and Definition~\ref{def:obs-entropy} is that quantity for cardinality in place of volume. The identification is a definition and is not an independent result. The fibres $c^{-1}(o)$ partition $\calH$, which is the content of the quotient.

\chapter{Distinguishability and Topology}
\label{ch:topology}

\section{Induced Topologies}

\begin{definition}[Collapse-Induced Topology]
For a rule $c$, with $O_c$ carrying the discrete topology, the \emph{$c$-induced topology} on $\calH$ is $\tau_c=\{c^{-1}(U)\mid U\subseteq O_c\}$, the initial topology of $c$.
\end{definition}

The open sets of $\tau_c$ are exactly the unions of $\sim_c$-classes, so $\tau_c$ is determined by the partition and conversely.

\begin{proposition}[Rule Change Induces Topology Change]
\label{prop:topology-change}
$\tau_{c_1}=\tau_{c_2}$ if and only if ${\sim_{c_1}}={\sim_{c_2}}$. If $c_1\preceq c_2$ then $\tau_{c_2}\subseteq\tau_{c_1}$, with strict inclusion exactly when $c_1$ distinguishes some pair that $c_2$ identifies.
\end{proposition}

\begin{proof}
A union of $\sim_c$-classes determines the partition because the classes are the minimal nonempty open sets. If $c_1\preceq c_2$, a union of $\sim_{c_2}$-classes is a union of $\sim_{c_1}$-classes, so $\tau_{c_2}\subseteq\tau_{c_1}$. Inclusion is strict exactly when the partitions differ: if a $\sim_{c_2}$-class properly contains a $\sim_{c_1}$-class $D$, then $D$ is open in $\tau_{c_1}$ but not in $\tau_{c_2}$, whose open sets are unions of $\sim_{c_2}$-classes.
\end{proof}

\begin{definition}[Observational Pseudometric]
$d_c(H_1,H_2)=\mathbf 1[c(H_1)\ne c(H_2)]$. It is a pseudometric, and $d_c(H_1,H_2)=0$ iff $H_1\sim_cH_2$.
\end{definition}

\section{Observational Completeness}

\begin{definition}[Observational Completeness and Kernel]
A rule $c$ is \emph{observationally complete} if it is injective. Its \emph{kernel} is $\ker c=\{(H_1,H_2)\mid c(H_1)=c(H_2)\}$, so $c$ is complete iff $\ker c$ is the diagonal.
\end{definition}

\begin{proposition}[Completeness of the Canonical Rules]
The rule $c_I$ is complete. The rules $c_{LW}$ and $c_{\mathrm{acc}}$ are not.
\end{proposition}

\begin{proof}
$c_I$ is the identity. For $c_{LW}$ take the legal histories $H_1=[\Pop(x)]$ and $H_2=[\Bind(a,b),\Pop(x)]$, both mapped to $\{x\}$. For $c_{\mathrm{acc}}$ take $H_1=[\Pop(x),\Pop(y)]$ and $H_2=[\Pop(y),\Pop(x)]$, both mapped to the count map with value $1$ at $x$ and $y$.
\end{proof}

\begin{remark}
$c_{\mathrm{acc}}$ identifies histories that are permutations of one another, up to events that it ignores. It is order-forgetful: it records what happened but not when relative to other events.
\end{remark}

\section{The Inverse Problem}

The inverse problem for a rule $c$ is to characterize the fibre $c^{-1}(o)$ of an observed state $o$, which answers the question of which histories could have produced an observation. Some fibres are computable in closed form. On Pop-only legal histories from $\Omega_0$, both $c_{LW}$ and $c_{\mathrm{acc}}$ record the set $P$ of popped symbols, and the fibre of $P$ consists of the $|P|!$ orderings of $P$. On all legal histories the fibre of $c_{\mathrm{acc}}$ is infinite because Bind, Refuse, and Collapse events can be inserted without limit. A general characterization of fibres, and of the subclasses of histories on which a given rule is injective, is open.

\chapter{Beta-Reduction and Closures}
\label{ch:lambda}

\section{A Modeling Convention}

In the standard account, computation is explained through functions. In Spherepop the lambda events $\mathrm{LamIntro}(x)$ and $\mathrm{Apply}(N)$ are added to the alphabet, and function application is encoded as a pattern in the history. The encoding needs more than the two events, because beta-reduction depends on the body of the abstraction, on variable identity, and on capture-avoiding substitution, none of which a pair of events carries.

\begin{definition}[Lambda History Fragment]
The application of $\lambda x.M$ to $N$ generates the history fragment $[\mathrm{LamIntro}(x),\mathrm{Apply}(N)]$, where the events refer to the term $M$ and the term $N$ by identity in a term store. As a modeling convention, the parameter $x$ is treated as a symbol whose option set is the set of possible arguments, and the event $\mathrm{Apply}(N)$ commits it.
\end{definition}

\begin{definition}[Substitution Rule]
Let $c_{\mathrm{subst}}(H)$ be the partial map sending the binding occurrence of $\mathrm{LamIntro}(x)$ to $N$ whenever $\mathrm{Apply}(N)$ is the first $\mathrm{Apply}$ event after an occurrence of $\mathrm{LamIntro}(x)$ in $H$.
\end{definition}

\begin{remark}[What Is and Is Not Claimed]
For $H=[\mathrm{LamIntro}(x),\mathrm{Apply}(N)]$ one has $c_{\mathrm{subst}}(H)=\{x\mapsto N\}$, and the contractum $M[x:=N]$ is obtained by applying this map as a capture-avoiding substitution to $M$. If the same variable name occurs in several abstraction events, a map indexed by names alone can assign incompatible arguments to one name, so the map is indexed by binding-occurrence identifiers and not by names. This is a restatement of beta-reduction in terms of an observation of the application history and not a derivation of the lambda calculus from histories: free variables, binding, and substitution remain external to the encoding. The convention gives a precise reading of the informal claim that application is commitment, since $x$ can thereafter denote only $N$. It does not show that functions are redundant as a notion.
\end{remark}

\begin{remark}[Reduction Order]
Distinct reduction orders of one term produce distinct histories, since the order of $\mathrm{Apply}$ events differs. The Church--Rosser property of the lambda calculus \cite{barendregt} says that the normal forms agree. If the retained history and the term store determine the initial term and its reduction sequence, a partial observation returning the normal form is straightforward to define on normalizing executions. The open question is stronger: whether such an observation can be constructed compositionally, computed from the retained events alone, and extended to nonnormalizing computations, so that histories of different reduction orders are observationally equivalent exactly when their normal forms are equal.
\end{remark}

\begin{definition}[Closure]
A \emph{closure} is a pair $(\lambda x.M,\rho)$ where $\rho$ is the environment of binding events current when the abstraction was formed.
\end{definition}

A closure records a suspended continuation together with the commitments made before its formation, and it is restored when the closure is applied.

\begin{implbox}{Implementation: \texttt{eval/value.rs}}
\begin{lstlisting}
Value::Closure {
    param: Symbol,
    param_ty: Type,
    body: Box<Term>,
    env: Env,
}
\end{lstlisting}
The \texttt{env} field carries the commitments made at closure creation and is restored on application.
\end{implbox}

\chapter{Compiler Correctness as History Equality}
\label{ch:compiler}

\section{The Criterion}

The usual criterion for compiler correctness is that the compiled program produces the same output as the interpreted program on every input. In a language whose primary object is the history, two programs can agree on every final observation and still construct different histories, and those histories are part of what the program is in this setting.

\begin{definition}[Interpreter, Compiler, and Machine for the Core Fragment]
\label{def:correctness}
The interpreter is $\eval$ of Section~\ref{sec:core}. The \emph{event IR} is a list of events from $\Pop(x)$, $\Rfuse(x,r)$, $\Bind(a,b)$, $\Col(x,c)$, each carrying its argument. For terms whose type is $\Adm{\cdot}$ let $\mathrm{res}(\mathrm{pop}(x))=x$ and $\mathrm{res}(t_1;t_2)=\mathrm{res}(t_2)$. The compiler is
\begin{align*}
C(\mathrm{pop}(x))&=[\Pop(x)],\\
C(\mathrm{refuse}(x,r))&=[\Rfuse(x,r)],\\
C(\mathrm{bind}(a,b))&=[\Bind(a,b)],\\
C(t_1;t_2)&=C(t_1)\hconcat C(t_2),\\
C(\mathrm{collapse}(t,c))&=C(t)\hconcat[\Col(\mathrm{res}(t),c)]
\end{align*}
and the machine executes $\mathrm{run}(C(t),W)$, which is undefined when a Pop event is not applicable. A compiler is \emph{correct} for a program $p$ and world $W$ if $\eval(p,W)$ succeeds with world $W'$ exactly when $\mathrm{run}(C(p),W)$ is defined, and then $W'=\mathrm{run}(C(p),W)$, in particular with equal histories.
\end{definition}

\begin{theorem}[History Equality for the Core Fragment]
\label{thm:replay}
Let $t$ be a well-typed core term, $\Gamma\vdash t:T$, with its symbols declared and the symbol-typing restrictions of the preservation theorem. For every world $W$: $\eval(t,W)=(v,W')$ if and only if $\mathrm{run}(C(t),W)=W'$, and $\eval(t,W)=\blocked(x)$ if and only if $\mathrm{run}(C(t),W)$ is undefined. In particular the history of $\eval(t,W)$ equals the history of $\mathrm{run}(C(t),W)$ whenever both succeed.
\end{theorem}

\begin{proof}
We prove, by induction on $t$, the stated equivalence together with the auxiliary claim that if $\Gamma\vdash t:\Adm{T'}$ then $\mathrm{res}(t)$ is defined and any successful evaluation of $t$ returns $\mathrm{adm}(\mathrm{res}(t))$. For $\mathrm{pop}(x)$ both sides succeed exactly when $x\in\Omega_W$ and produce $P_xW$; the auxiliary claim holds with $\mathrm{res}=x$. The cases $\mathrm{refuse}$ and $\mathrm{bind}$ are total on both sides and produce $R_{x,r}W$ and $B_{a,b}W$. For $\mathrm{collapse}(t,c)$, typing gives $\Gamma\vdash t:\Adm{T'}$, so $\mathrm{res}(t)=x$ is defined and by the induction hypothesis $\eval(t,W)=(\mathrm{adm}(x),W')$ iff $\mathrm{run}(C(t),W)=W'$, with blocking corresponding. Then $\eval$ continues with $C_{x,c}W'$ and the machine with $\mathrm{app}(\Col(x,c),W')$, which are equal. For $t_1;t_2$, $\mathrm{run}(C(t_1)\hconcat C(t_2),W)=\mathrm{run}(C(t_2),\mathrm{run}(C(t_1),W))$ and $\eval(t_1;t_2,W)=\eval(t_2,W_1)$ with $W_1$ the world after $t_1$; the induction hypothesis applied twice gives the claim, and the auxiliary claim for $t_1;t_2$ is the one for $t_2$.
\end{proof}

\begin{corollary}[Preservation and Reflection of History Identity]
\label{cor:full-faithful}
For well-typed $p_1,p_2$ and a world $W$ at which both evaluate, $\eval(p_1,W)$ and $\eval(p_2,W)$ yield equal histories if and only if $\mathrm{run}(C(p_1),W)$ and $\mathrm{run}(C(p_2),W)$ do, and then for every collapse rule $c$ the observations agree as well.
\end{corollary}

\begin{proof}
Immediate from Theorem~\ref{thm:replay} applied to each program. The final clause holds since $c$ is a function of the history.
\end{proof}

\begin{remark}
The corollary states that the compiler preserves and reflects equality of histories. It does not make the compiler a full and faithful functor, which would require a category of programs and a proof about morphisms, neither of which is defined here, and the term is not claimed.
\end{remark}

\begin{example}[History Equality Is Strictly Stronger]
\label{ex:strict}
The programs $\mathrm{pop}(a);\mathrm{pop}(b)$ and $\mathrm{pop}(b);\mathrm{pop}(a)$ from a world with $\Omega\supseteq\{a,b\}$ end with the same option space and, under $c_{\mathrm{acc}}$, the same observation. Their histories differ. A criterion based on final option space or on $c_{\mathrm{acc}}$ would accept a compiler that swapped them, and history equality would reject it.
\end{example}

\begin{remark}[Scope and Terminology]
The proof is short because the fragment has no control flow, closures, or recursion. Extending it to the lambda fragment requires a treatment of closures that is not given. The name \emph{replay equivalence} used for Theorem~\ref{thm:replay} refers to equality of the histories produced by interpretation and by execution of compiled code, and is distinct from deterministic re-execution of a recorded log, which is a different property treated in Chapter~\ref{ch:receipts}. Each passing instance of the corresponding test in the implementation checks the property for one program and is evidence, not proof.
\begin{lstlisting}
assert_eq!(world_interp.history, world_compiled.history);
\end{lstlisting}
\end{remark}

\chapter{Representations Change Topologies}
\label{ch:repr}

\section{Kernel Embeddings and the Separation of Measure}

Santoro, Waghmare, and Panaretos \cite{swp} study kernel covariance embeddings of probability measures. In the setting of their paper, testing the equality of two non-atomic Borel probability measures on a locally compact Polish space is equivalent to testing the singularity of two centered Gaussian measures on a reproducing kernel Hilbert space, the Gaussians being defined by the kernel covariance embedding. The proof uses the Feldman--Hájek dichotomy \cite{feldman,hajek}, according to which two Gaussian measures are either equivalent or mutually singular, and the authors describe the consequence as a separation of measure phenomenon in which small perturbations of a distribution are maximally magnified in its Gaussian embedding. The precise conditions on the kernel are given in the paper and are not restated here.

\begin{fact}[Santoro, Waghmare, and Panaretos]
\label{fact:swp}
Under the hypotheses of \cite{swp}, for non-atomic $P\ne Q$ the centered Gaussian embeddings $\mathcal N(0,S_P)$ and $\mathcal N(0,S_Q)$ are mutually singular, while $P=Q$ gives the same Gaussian.
\end{fact}

This is a result of that paper and is used here as a cited input. It is not proved in this monograph.

\begin{definition}[Representation Topology]
A \emph{representation} is a map $\rho:X\to Y$ with $Y$ a topological space. The \emph{pullback topology} on $X$ is $\{\rho^{-1}(U)\mid U\text{ open in }Y\}$.
\end{definition}

For collapse rules, with $O_c$ discrete, this is the topology $\tau_c$ of Chapter~\ref{ch:topology}. For the Gaussian embedding the choice of topology on the target matters, and the comparison is as follows.

\begin{proposition}[Embedding Changes Topology]
\label{thm:rep-topology}
Assume Fact~\ref{fact:swp} on the space $X=[0,2]$, and let $\mathcal M$ be the set of non-atomic Borel probability measures on $X$. Give Gaussian measures the total variation topology and give $\mathcal M$ the topology of weak convergence. The pullback of the total variation topology under $P\mapsto\mathcal N(0,S_P)$ is discrete on $\mathcal M$, while the weak topology on $\mathcal M$ is not discrete.
\end{proposition}

\begin{proof}
For $P\ne Q$ in $\mathcal M$ the Gaussians are mutually singular, so their total variation distance is maximal, and the pullback of the total variation metric is the discrete metric. Hence every point of $\mathcal M$ is isolated in the pullback topology. In the weak topology the measures $P_n=\mathrm{Unif}[0,1+1/n]$ are non-atomic, distinct from $P=\mathrm{Unif}[0,1]$, and converge weakly to $P$, so $P$ is not isolated.
\end{proof}

\begin{remark}
The identity representation on $\mathcal M$ and the Gaussian embedding therefore induce different topologies on the same set, in the sense of Proposition~\ref{thm:rep-topology}. The collapse case is analogous in that a change of rule changes the topology on $\calH$ (Proposition~\ref{prop:topology-change}). The two settings differ in kind. For collapse rules the topology is determined by a partition of a discrete set and the change is a design choice. For the embedding the change comes from a limit theorem about a particular map, and the pullback topology is discrete because the embedding is injective on $\mathcal M$ and maximally separating. Fact~\ref{fact:swp} does not by itself identify the Gaussian representation as the unique one with this property, and no uniqueness claim is made. The comparison is structural and the two settings do not share a common theorem beyond the elementary fact that a map induces a topology.
\end{remark}

\section{CLIO Projections}

A CLIO projection is a surjection $\pi:X\to M$ from a representation space onto a space of observational strata, with fibre $\pi^{-1}(m)$ over a stratum and representational entropy $S_\pi(m)=\log\mathrm{Vol}(\pi^{-1}(m))$ \cite{clio}. Collapse rules are CLIO projections in the discrete case, with $X=\calH$, $M=\calH/{\sim_c}$, and volume replaced by cardinality, so that the fibre of a stratum is the equivalence class and its entropy is the logarithm of the class size on bounded histories (Definition~\ref{def:obs-entropy}). This identification is a dictionary and not a theorem.

\section{Milestones}

\chapter{Observations from the Implementation}
\label{ch:lessons}

Four points arose while implementing the calculus, and each sharpened a definition. The first concerns refusal. A refusal event that records only a symbol documents little, because the reason for the refusal is the information a reader needs, and the reason was therefore made part of the event and of the type. The second concerns observation: once state is derived from a history, the question of observable under what rule must be answered at every call, which led to the collapse rule as an explicit parameter. The third is the conflict between interpreter and checker over free variables, described in Chapter~\ref{ch:worlds}, which showed that the checker's behavior depends on an assumption about the boundary of the world that had not been stated. The fourth is the correctness criterion. Once the compiler and interpreter were both required to produce histories, equality of histories was the natural strict criterion, and Example~\ref{ex:strict} shows why a weaker criterion would be inadequate.

A caution applies to what these points show. They show that specific ambiguities in the informal design were resolved by the act of implementing, and the resolutions are the definitions above. They do not show that implementation is a form of argument for the underlying view, and the evidential status of the test suite is stated in Appendix~\ref{app:witnesses}.

\chapter{Continuation Spaces and Contextual Admissibility}
\label{ch:cont}

\section{Continuations}

The original semantics describes the future only through two sets of symbols. A more discriminating object is the set of entire continuations a history permits, since dependencies, ordering constraints, intermediate obligations, and terminal conditions are properties of sequences and not of single options.

\begin{definition}[Admissible Histories and Continuation Space]
\label{def:cont}
A \emph{context} $\Gamma$ determines a set $\mathcal A_\Gamma\subseteq\calH$ of admissible histories, assumed prefix-closed. The \emph{continuation space} of $H\in\mathcal A_\Gamma$ is $\mathrm{Cont}_\Gamma(H)=\{K\in\calH\mid H\hconcat K\in\mathcal A_\Gamma\}$.
\end{definition}

\begin{proposition}[Derivatives]
\label{prop:derivative}
If $\mathcal A_\Gamma$ is prefix-closed and $H\hconcat K\in\mathcal A_\Gamma$ then $\mathrm{Cont}_\Gamma(H\hconcat K)=K^{-1}\mathrm{Cont}_\Gamma(H):=\{L\mid K\hconcat L\in\mathrm{Cont}_\Gamma(H)\}$. Moreover $\varepsilon\in\mathrm{Cont}_\Gamma(H)$ iff $H\in\mathcal A_\Gamma$, and if $H\hconcat K\notin\mathcal A_\Gamma$ then $H\hconcat K\hconcat L\notin\mathcal A_\Gamma$ for every $L$.
\end{proposition}

\begin{proof}
$L\in\mathrm{Cont}(H\hconcat K)$ iff $(H\hconcat K)\hconcat L\in\mathcal A_\Gamma$ iff $K\hconcat L\in\mathrm{Cont}(H)$. The last claim is the contrapositive of prefix closure.
\end{proof}

In the original calculus, take $\mathcal A_{\Omega_0}$ to be the set of histories legal from $(\varepsilon,\Omega_0)$. It is prefix-closed, and $\mathrm{Cont}(H)$ is the set of histories legal from $\Omega_H$, the option space reached by $H$, so it depends on $H$ only through $\Omega_H$.

\section{Refusal Is Contextual}

The refusal set of Definition~\ref{def:admissible-futures} subtracts every symbol that has ever been refused. That treats refusal as permanent exclusion and cannot represent several ordinary situations: evidence that has become stale, a temporary resource constraint, a change of authorization, a repaired dependency, or the later satisfaction of an obligation that was unmet. A refusal concerns a particular proposal in a particular context. The revised theory distinguishes four notions: structural possibility, given by the option space; present admissibility, given by $\mathcal A_\Gamma$ for the current context $\Gamma$; historical refusal, a record that a proposal was refused for a stated reason in a stated context; and reconsideration, the conditions under which a refused proposal may again be admissible.

\begin{example}[Admissibility That Returns]
\label{ex:returns}
Let a proposal $\tau$ be admissible at a head $H_0$ in context $\Gamma_0$. Another proposal commits, producing $H_1=H_0\hconcat[e]$, and in the resulting context $\Gamma_1$ the evidence for $\tau$ is bound to a stale head, so $\tau\notin\mathrm{Cont}_{\Gamma_1}(H_1)$. After $\tau$ is rebased onto $H_1$ and re-verified, a rebased proposal $\tau'$ is admissible in $\Gamma_1$. The set of admissible continuations has contracted and then admitted a successor of $\tau$, and the refusal of $\tau$ remains on record without excluding $\tau'$. This is the pattern of the parser example of Chapter~\ref{ch:kernels}.
\end{example}

\section{What Is Invariant}

The three changes one may track along a run are distinct. Historical growth is the prefix order $H_t\preceq H_{t+1}$ of an append-only authoritative history. Structural contraction is the inclusion $\Omega_{t+1}\subseteq\Omega_t$ of the option space. Admissibility evolution is the passage $\mathcal A_t\to\mathcal A_{t+1}$ of the admissible set.

\begin{proposition}[Only Growth Is General]
Historical growth holds in every system whose authoritative history is append-only. Structural contraction holds in the original calculus (Theorem~\ref{thm:conservation}) and fails in systems with a refining operation. Admissibility evolution need not be monotone in either direction.
\end{proposition}

\begin{proof}
The first claim is the definition of append-only. For the second, extend the calculus by an operation $\mathrm{Refine}(x;x_1,x_2)$ with $\mathrm{app}(\mathrm{Refine}(x;x_1,x_2),(H,\Omega))=(H\hconcat[\mathrm{Refine}],\ (\Omega\setminus\{x\})\cup\{x_1,x_2\})$ for $x\in\Omega$, with $x_1,x_2$ fresh; then $|\Omega|$ increases by one. Example~\ref{ex:returns} shows non-monotone admissibility.
\end{proof}

The slogan that computation is the progressive restriction of possibility is accurate for the finite-option calculus of Part~\ref{part:pop-calc}. Generation, decomposition, repair, delegation, and changes in available resources can all enlarge the set of feasible continuations while history grows.

\chapter{Distinction and Continuation}
\label{ch:distinction}

\section{A Hierarchy of Equivalences}

Several equivalences on histories are in use, each the kernel of a function of the history. Exact equivalence is equality. Observational equivalence $\sim_c$ is relative to a rule. Continuation equivalence in a context is $H_1\sim_{\mathrm{cont}}H_2$ iff $\mathrm{Cont}_\Gamma(H_1)=\mathrm{Cont}_\Gamma(H_2)$. Authorization equivalence compares the set of continuations that a given principal is authorized to propose, and evidentiary equivalence compares the set of continuations for which sufficient evidence is on file. Exact equality refines all of the others, since each is a function of the history. The others are in general incomparable, and which of them a system must preserve depends on the guarantees it claims to give. Exact replay remains a useful strong condition but is no longer the only meaningful criterion of preservation.

\section{Observation Can Destroy Continuations}

\begin{theorem}[Non-Factorization]
\label{thm:nonfactor}
Let $q$ be an observation and suppose $q(H_1)=q(H_2)$ while $\mathrm{Cont}(H_1)\ne\mathrm{Cont}(H_2)$. Then no function $g$ satisfies $\mathrm{Cont}=g\circ q$. In particular no policy that is a function of the observable state alone can reproduce the continuation space of both histories. In general, $\mathrm{Cont}$ factors through $q$ if and only if ${\sim_q}\subseteq{\sim_{\mathrm{cont}}}$.
\end{theorem}

\begin{proof}
If $\mathrm{Cont}=g\circ q$ then $q(H_1)=q(H_2)$ would give equal continuation spaces. The last statement is Theorem~\ref{thm:factorization} applied to $q$ and $\mathrm{Cont}$.
\end{proof}

The theorem gives the state illusion an operational reading: the loss is not only that the history cannot be recovered, but that correct future action may become indeterminable from the observation.

\begin{proposition}[Canonical Rules and Continuations]
\label{prop:cont-rules}
In the original calculus, $c_I$ and $c_{\mathrm{acc}}$ are continuation-sufficient on histories legal from $(\varepsilon,\Omega_0)$, and $c_{LW}$ is not.
\end{proposition}

\begin{proof}
Continuations depend only on $\Omega_H=\Omega_0\setminus\{x\mid\Pop(x)\in H\}$. Since each symbol is popped at most once, $c_{\mathrm{acc}}(H)(x)=1$ iff $x\notin\Omega_H$, so $c_{\mathrm{acc}}$ determines $\Omega_H$, and $c_I$ determines everything. For $c_{LW}$ take $H_1=[\Pop(x),\Rfuse(x,r)]$ and $H_2=\varepsilon$: both have $c_{LW}=\varnothing$, but $[\Pop(x)]$ is a legal continuation of $H_2$ and not of $H_1$.
\end{proof}

\section{Forward Projection}

\begin{definition}[Reachability Geometry and Forward Projection]
Let $\mathcal F=2^{\Omega_0}\times2^{\Omega_0}$. For a legal history $H$ let $\rho(H)=(\calA^{\mathrm{hist}}(H),\Omega_H)\in\mathcal F$.
\end{definition}

No containment between the two components is assumed. After $\Rfuse(x,r)$ with $x\in\Omega$ the symbol $x$ is in the option space and not in $\calA^{\mathrm{hist}}$, so a pair with $\Omega\subseteq\calA$ is not preserved by refusal.

\begin{definition}[Deformation]
Each event induces $\delta_e:\mathcal F\to\mathcal F$ with $\delta_{\Pop(x)}(\calA,\Omega)=(\calA,\Omega\setminus\{x\})$, $\delta_{\Rfuse(x,r)}(\calA,\Omega)=(\calA\setminus\{x\},\Omega)$, and the identity for Bind and Collapse.
\end{definition}

\begin{proposition}[Histories as Composed Deformations]
\label{prop:deformation}
For $H=[e_1,\dots,e_n]$ legal from $(\varepsilon,\Omega_0)$, $\rho(H)=(\delta_{e_n}\circ\cdots\circ\delta_{e_1})(\Omega_0,\Omega_0)$.
\end{proposition}

\begin{proof}
By induction on $n$. For $n=0$, $\rho(\varepsilon)=(\Omega_0,\Omega_0)$. Appending $e$ changes $\calA^{\mathrm{hist}}$ and $\Omega$ exactly as $\delta_e$ does, by Definition~\ref{def:admissible-futures} and Definition~\ref{def:world}.
\end{proof}

\begin{theorem}[When Observation Factors Through Reachability]
\label{thm:two-proj}
A rule $c$ factors through $\rho$ on legal histories, that is, $c=\bar q\circ\rho$ for some $\bar q$, if and only if ${\sim_\rho}\subseteq{\sim_c}$. The rule $c_{\mathrm{acc}}$ does. The rules $c_I$, $c_{LW}$, and $\pi_L$ for a prefix $L$ of a symbol $x$ do not.
\end{theorem}

\begin{proof}
The criterion is Theorem~\ref{thm:factorization}. For $c_{\mathrm{acc}}$, $\rho(H)$ determines $\Omega_H$ and hence the popped set, which determines $c_{\mathrm{acc}}(H)$ on legal histories. For the others, $[\Pop(x),\Rfuse(x,r)]$ and $[\Rfuse(x,r),\Pop(x)]$ are both legal and both have $\rho=(\Omega_0\setminus\{x\},\Omega_0\setminus\{x\})$, while $c_I$, $\pi_L$ distinguish them by order and $c_{LW}$ gives $\varnothing$ and $\{x\}$ respectively.
\end{proof}

The two projections, the backward observation $c$ and the forward projection $\rho$, are therefore independent maps from a common history-bearing world, and factorization of one through the other is a theorem under the stated condition. Histories with identical reachability can contain different past events, so factorization cannot be assumed. When it does hold, fibre sizes decompose additively: $|[H]_c\cap\calH_{\le n}|=\sum_f|\rho^{-1}(f)\cap\calH_{\le n}|$ over the geometries $f$ in the image of the class. The entropy of a class is accordingly the logarithm of this sum and not a sum of logarithms.

\chapter{Obstruction and Repair}
\label{ch:obstruction}

\section{Local Executability and Global Realizability}

An operation may be individually admissible, and every component of a proposed computation may satisfy its local specification, while the composite computation cannot be realized. Chapter~\ref{ch:nested} gives a precise instance. Obstructions are of several kinds. A logical obstruction is a violated invariant. A resource obstruction is a missing budget or capacity. A temporal obstruction is an ordering or deadline that cannot be met. A compositional obstruction arises only from the combination of locally admissible parts. An authorization obstruction is the absence of authority to commit, and an evidentiary obstruction is the absence of sufficient evidence. The kinds are not mutually exclusive, and the same failed continuation can exhibit several.

\begin{proposition}[Obstruction Survives Extension]
If $H\hconcat K\notin\mathcal A_\Gamma$ then no extension $K\hconcat L$ is admissible in $\Gamma$.
\end{proposition}

\begin{proof}
Prefix closure, Proposition~\ref{prop:derivative}.
\end{proof}

An obstruction cannot be removed by continuing along the obstructed path. It disappears only by a change of context (new evidence, additional authorization, more resources, a repaired dependency) or by choosing a different continuation. Which obstructions disappear under refinement of a proposal into smaller steps, and which survive every admissible decomposition, is a question the taxonomy makes precise, and the compositional case of Chapter~\ref{ch:gluing} is one in which the obstruction is a property of the interface of the parts and survives the choice of internal decomposition.

\section{Corrective Navigation}

Historical irreversibility is distinct from recoverability of configurations. By Corollary~\ref{cor:irrev} a world cannot return to an earlier world, yet an observable state can: $c_{LW}(\varepsilon)=c_{LW}([\Rfuse(x,r)])$. A system cannot erase the fact that an erroneous operation occurred, but it can undertake a further continuation that restores an acceptable configuration, $H'=H\hconcat E_{\mathrm{error}}\hconcat E_{\mathrm{repair}}$.

\begin{definition}[Repair]
Let $e$ be an event of $H$ and $\mathrm{Ob}(e)$ the set of obligations that $e$ created or left unsatisfied. A \emph{repair} of $e$ is a continuation $E$ that names $e$ as its target and discharges a stated subset of $\mathrm{Ob}(e)$, leaving a residual $\mathrm{Ob}(e)\setminus\mathrm{disch}(E)$ that is recorded. A repair is \emph{certified} if its discharge claims are supported by evidence under the same rules as any other continuation.
\end{definition}

A repair is not the inverse of a history extension. It is a new continuation, subject to the admissibility conditions of any continuation, whose purpose is to discharge obligations created or left unsatisfied by an earlier one. A repair must identify an existing historical event, and a repair that names no target is refused as unestablished. The repair-target fixture of Chapter~\ref{ch:kernels} exercises exactly this requirement.

\chapter{Structured Admissibility}
\label{ch:structured}

A scalar admissibility field $\phi:\calH\to[0,1]$ assigns a degree of admissibility to each history. It is inadequate as a primary object, because a history may be structurally valid but unauthorized, supported by evidence but infeasible within the available budget, or locally certified but globally obstructed.

\begin{definition}[Admissibility Profile]
A \emph{profile} of a pair $(H,K)$ is a tuple $\mathbf a(H,K)=(a_{\mathrm{str}},a_{\mathrm{res}},a_{\mathrm{evid}},a_{\mathrm{auth}},a_{\mathrm{comp}})$ with each component in its own value set $P_i$, not necessarily numerical and not necessarily commensurable with the others. A continuation is \emph{admissible} if each component satisfies its own acceptance predicate.
\end{definition}

\begin{proposition}[Scalarization Identifies Distinct Failures]
Take two Boolean components, $a_{\mathrm{valid}}$ and $a_{\mathrm{auth}}$, and the mean $s(a)=\tfrac12(a_{\mathrm{valid}}+a_{\mathrm{auth}})$. Then $s(1,0)=s(0,1)=\tfrac12$, although $(1,0)$ describes a valid but unauthorized continuation and $(0,1)$ an authorized but invalid one. Any symmetric aggregation of the two components identifies these profiles.
\end{proposition}

\begin{proof}
A symmetric function takes equal values on $(1,0)$ and $(0,1)$. For the mean the common value is $\tfrac12$.
\end{proof}

The two failures call for different remedies, obtaining authority in the first case and correcting the transformation in the second, so the identification discards the information that determines what to do next. A threshold on $s$ can still separate $(1,1)$ from the rest, so the loss concerns diagnosis and not the accept decision.

\begin{remark}
Scalar fields remain useful as derived representations for a particular application, provided that the information they discard is stated. The proposition is limited to symmetric aggregations, and asymmetric weightings avoid this particular identification at the cost of ranking one kind of failure above the other.
\end{remark}

\begin{definition}[Counting Field]
For $k\ge1$ and a finite alphabet with $\mathrm{Leg}_k(\varepsilon)\ne\varnothing$, let $\mathrm{Leg}_k(H)$ be the set of histories of length $k$ legal from the world reached by $H$, and $\phi_k(H)=|\mathrm{Leg}_k(H)|/|\mathrm{Leg}_k(\varepsilon)|\in[0,1]$, so that the denominator is nonzero. The pullback is defined for legal concatenations. For a history $K$ write $(K^*\phi)(H)=\phi(H\hconcat K)$.
\end{definition}

\begin{theorem}[Monotone Counting Field]
\label{thm:field-deform}
For every event $e$ and legal $H$, $\phi_k(H\hconcat[e])\le\phi_k(H)$, with equality when $e$ is not a Pop event. The pullbacks compose contravariantly in the concatenation order: $((K_1\hconcat K_2)^*\phi)(H)=(K_1^*(K_2^*\phi))(H)$.
\end{theorem}

\begin{proof}
Legality of a continuation depends only on the option space, and legal continuations from a smaller option space are legal from a larger one, since the only premise is $x\in\Omega$. Appending an event does not enlarge $\Omega$, so $\mathrm{Leg}_k(H\hconcat[e])\subseteq\mathrm{Leg}_k(H)$, with equality unless $e$ is a Pop event. The denominators coincide, since the numerator for $\varepsilon$ bounds both. For the second claim, $((K_1\hconcat K_2)^*\phi)(H)=\phi(H\hconcat K_1\hconcat K_2)=(K_2^*\phi)(H\hconcat K_1)=(K_1^*(K_2^*\phi))(H)$.
\end{proof}

Monotonicity is a property of this particular field, which counts legal continuations. It does not hold for an arbitrary function $\phi:\calH\to[0,1]$, which can be chosen to increase under Pop. Order-preserving conditions must be specified, and the field above satisfies them because it is defined from the set of continuations.

\chapter{Observation and Commitment}
\label{ch:separation}

Chapter~\ref{ch:quotient} uses Collapse for an observation: a function from histories that forgets distinctions. The development protocol uses COLLAPSE for something else, the admission of a certified transformation into authoritative history. The two operations differ in kind and are distinguished here.

\begin{definition}[Observation and Commitment]
\label{def:commit}
\emph{Observational collapse} is a total function $q_c:\calH\to\calH/{\sim_c}$. \emph{Authoritative commitment} is a partial operation $\mathsf{commit}:\calH_{\mathrm{auth}}\times\mathcal S_{\mathrm{cert}}\rightharpoonup\calH_{\mathrm{auth}}$, where an element $s=(\tau,\beta,\omega,\alpha)$ of $\mathcal S_{\mathrm{cert}}$ is a candidate transformation $\tau$ with a base version $\beta$, an evidence record $\omega$, and an authorization $\alpha$. It is defined at $(H,s)$ exactly when $\beta=\mathrm{head}(H)$ and the candidate is valid, certified by $\omega$, and authorized by $\alpha$ (Chapter~\ref{ch:vca}), and then $\mathsf{commit}(H,s)=H\hconcat[\mathrm{ev}(s)]$.
\end{definition}

The first operation forgets distinctions relative to a rule. The second extends an authoritative record subject to certification and authorization. In particular $q_c$ is in general non-injective and is defined on every history, while $\mathsf{commit}(H,s)$ is a proper extension of $H$ whenever it is defined.

\section{Working State and Authoritative History}

The original world contains a history and an option space. A world suited to the protocol contains more, because exploratory computation can be mutable, disposable, and even contradictory without corrupting the authoritative record.

\begin{definition}[Protocol World]
A \emph{protocol world} is $W=(H_{\mathrm{auth}},J,L,E,A,\mathcal O)$ with an authoritative history $H_{\mathrm{auth}}$, provisional journals $J=\{J_s\}$ one per open sphere $s$, an audit ledger $L$, an evidence store $E$, authorizations $A$, and outstanding obligations $\mathcal O$. Only $\mathsf{COLLAPSE}$ extends $H_{\mathrm{auth}}$. The operations $\mathsf{POP}$, $\mathsf{BIND}$, $\mathsf{TRANSFORM}$, $\mathsf{VERIFY}$, and $\mathsf{REFUSE}$ act on journals, the ledger, and the evidence store.
\end{definition}

\begin{proposition}[Isolation of Authoritative History]
\label{prop:isolation}
Every protocol transition other than $\mathsf{COLLAPSE}$ leaves $H_{\mathrm{auth}}$ unchanged.
\end{proposition}

\begin{proof}
By the definition of the operations: each of the others is specified to write to $J$, $L$, or $E$ only.
\end{proof}

Authoritative history is therefore not a transcript of everything the system has done. Provisional states in a journal may be discarded, and the ledger records that proposals were made and refused. Whether the ledger must itself be retained is a separate policy question treated in Part~\ref{part:memory}.

\begin{proposition}[Serialization of Commits]
\label{prop:serial}
Assume the head digest is injective on authoritative histories. This is an idealization: SHA-256 cannot be injective on an unrestricted set of histories, and for the concrete digest the conclusion holds computationally and conditionally on collision resistance. If $s_1\ne s_2$ have the same base $\beta=\mathrm{head}(H)$ and $\mathsf{commit}(H,s_1)$ is defined, then $\mathsf{commit}(\mathsf{commit}(H,s_1),s_2)$ is undefined.
\end{proposition}

\begin{proof}
After the first commit the head is $\mathrm{head}(H\hconcat[\mathrm{ev}(s_1)])\ne\mathrm{head}(H)=\beta$ by injectivity, so the base condition for $s_2$ fails.
\end{proof}

The proposition is the formal content of the rule that a commit is evaluated atomically against the current head: of two candidates prepared against the same head, at most one commits without rebasing.

\chapter{Validity, Certification, and Authorization}
\label{ch:vca}

Three predicates are distinguished, and none may be silently substituted for another. For a candidate $\tau$, a history $H$, a context $\Gamma$, evidence $\omega$, and an authorization $\alpha$:
\[
\begin{gathered}\mathrm{Valid}(\tau;H,\Gamma),\qquad\mathrm{Certified}(\tau;H,\Gamma,\omega),\\\mathrm{Authorized}(\tau;H,\Gamma,\alpha).\end{gathered}
\]
$\mathrm{Valid}$ states that the candidate satisfies the obligations of the context. $\mathrm{Certified}$ states that a deterministic checker accepts the evidence $\omega$ as establishing the obligations declared by the profile. $\mathrm{Authorized}$ states that the principal holds authority to commit $\tau$ at $H$, evaluated against the state before the transition. A \emph{profile} is \emph{sound} if $\mathrm{Certified}$ implies $\mathrm{Valid}$ for the obligations it declares.

\begin{proposition}[Non-Equivalence of Validity, Certification, and Authorization]
\label{prop:independence}
Under a sound profile, certification entails validity of the declared obligations, so the predicates are not logically independent. Each of the six remaining combinations of (valid, certified, authorized) is realized, namely every combination except those in which the candidate is certified and not valid. In particular no one of the three predicates entails another except that certification entails validity.
\end{proposition}

\begin{proof}
Take a profile declaring one obligation, that a function returns a nonnegative integer, with a checker that accepts a recorded proof of it. A candidate that fails the obligation, for which no evidence exists and no permission has been granted, is (no, no, no). The same candidate with permission granted by a principal holding blanket authority is (no, no, yes). A correct candidate with no evidence and no permission is (yes, no, no), and with permission is (yes, no, yes). A correct candidate with an accepted proof and no permission is (yes, yes, no), and with permission, evidence, and a current base is (yes, yes, yes). Certified without valid is excluded by soundness.
\end{proof}

Soundness is relative to the obligations the profile declares. A candidate can be valid for those obligations and invalid for an obligation of the surrounding context that the profile omits, and certification does not exclude this unless the profile is complete for the context.

A proof that a transformation is correct does not itself grant permission to commit it. Writing $A_{\mathrm{valid}}$, $A_{\mathrm{authorized}}$, and $A_{\mathrm{commit}}$ for the sets of candidates for which the respective predicate holds, $A_{\mathrm{commit}}=\{\tau\mid\mathsf{commit}\text{ is defined}\}\subseteq A_{\mathrm{valid}}\cap A_{\mathrm{authorized}}$ under a sound profile, and the inclusion is strict in general because commit additionally requires evidence, freshness of the base, and the commit rule.

\section{Removing Automatic Certification from Opening}

In the original calculus, \textsc{[T-Pop]} yields $\Adm{T}$ from any typing derivation, and Remark~\ref{rem:adm-scope} limits its meaning to structural commitment. A type system for the protocol must go further. Opening a sphere must not certify the transformation subsequently performed in it. The judgement forms are separate, and a certificate type is introduced by exactly one rule.
\[
\frac{\Gamma\vdash\tau:\mathrm{Cand}}{\Gamma\vdash\mathsf{pop}(\tau):\mathrm{Open}(\tau)}\ \textsc{[P-Open]}
\]
\[
\frac{\begin{array}{c}\Gamma\vdash u:\mathrm{Open}(\tau)\\\mathsf{check}(\omega,\tau,H)=\mathsf{accept}\quad h=\mathrm{head}(H)\end{array}}{\Gamma\vdash\mathsf{verify}(u,\omega):\mathrm{Cert}_{h,\sigma,v}(\tau,\omega)}\ \textsc{[P-Verify]}
\]
\[
\frac{\begin{array}{c}\Gamma\vdash c:\mathrm{Cert}_{h,\sigma,v}(\tau,\omega)\\\mathrm{Authorized}(\tau;H,\Gamma,\alpha)\quad h=\mathrm{head}(H)\end{array}}{\Gamma\vdash\mathsf{collapse}(c,\alpha):\mathrm{Committed}(\tau)}\ \textsc{[P-Commit]}
\]

\begin{proposition}[No Certificate from Opening]
In this system a derivation of $\Gamma\vdash t:\mathrm{Cert}_{h,\sigma,v}(\tau,\omega)$ contains an instance of \textsc{[P-Verify]}, and a derivation of $\mathrm{Committed}(\tau)$ contains instances of both \textsc{[P-Verify]} and the authorization premise.
\end{proposition}

\begin{proof}
The system is syntax-directed, and $\mathrm{Cert}$ and $\mathrm{Committed}$ occur in the conclusion of only \textsc{[P-Verify]} and \textsc{[P-Commit]} respectively. Inversion on the final rule gives the claim.
\end{proof}

The certificate type is indexed by the head $h$, the scope $\sigma$, and the verifier identity $v$ under which it was issued, so a certificate does not remain well typed after the authoritative head has moved. The commit rule binds the base version through the certificate index and requires $h=\mathrm{head}(H)$ at commitment. A certificate for an earlier head can be used only after an explicit evidence-transport judgement establishes that its index is applicable (Proposition~\ref{prop:reuse}), or after reissuance.

This is the correction of the automatic certification that \textsc{[T-Pop]} performs in the original calculus. It matters most for automated software development, where a generating component can be made to open spheres freely and must not thereby acquire certificates.

\section{Separation of Roles}

The process that generates a candidate continuation does not automatically hold the authority to certify it. The vocabulary of claims, evidence, warrants, defeaters, routing, adjudication, and standing developed in the Adversaria work is adopted for this purpose: a candidate is a claim, the evidence record is the warrant offered for it, a failed or contradicting check is a defeater, and the decision to commit is an adjudication made by a party with standing. The protocol requires that the checker be deterministic and independent of the proposer. The two properties are separate. Determinism gives reproducibility under identical inputs. Independence concerns the relation between the generator and the checking mechanism, since evidence produced by the proposer's own judgment is not independent evidence. Neither establishes soundness: a deterministic checker can consistently accept invalid transformations, an independently developed checker can contain errors, and a probabilistic verifier can offer meaningful soundness guarantees. Deterministic verification is adopted as the requirement of the present protocol and is not claimed necessary for every certification architecture.

\chapter{Evidence, Freshness, and Receipts}
\label{ch:receipts}

\section{Evidence Records}

An evidence record is bound to the exact candidate it supports. It has the form $\omega=(h,t,\sigma,v,\eta,F,r)$ with the head digest $h$ and candidate digest $t$ to which it applies, a scope $\sigma$, the verifier identity $v$ and the checker's output $\eta$, a footprint $F$, and a result $r$. Footprints are layered. The footprint actually observed by the checker can include information irrelevant to validity, so no inclusion between it and the footprint on which validity semantically depends is assumed. The condition that matters for soundness is $F_{\mathrm{semantic}}\subseteq F_{\mathrm{certified}}$: the certified footprint must contain every semantically relevant dependency, and only a certified footprint with this property justifies reuse.

\section{Freshness}

A certificate that was valid when issued can become insufficient after another sphere commits a conflicting transformation. This does not show that it was false when issued. It shows that its applicability changed, and historical acceptance must be distinguished from present applicability.

\begin{definition}[Faithful Footprint]
A footprint $F$ is \emph{faithful} for a candidate $\tau$ if $\mathrm{Valid}(\tau;H,\Gamma)$ depends on the state of $H$ only through its restriction to $F$.
\end{definition}

\begin{proposition}[Sound Evidence Reuse]
\label{prop:reuse}
Suppose $\omega$ certifies $\tau$ at head $H$ under a sound profile with a faithful footprint $F$, and the commits that extend $H$ to $H'$ leave the state restricted to $F$ unchanged. Then $\mathrm{Valid}(\tau;H',\Gamma)$.
\end{proposition}

\begin{proof}
Soundness gives $\mathrm{Valid}(\tau;H,\Gamma)$. Faithfulness makes validity a function of the restriction to $F$, which is the same at $H$ and $H'$.
\end{proof}

The conclusion is validity and not certification. The original certificate remains bound to the earlier head, and the commit rule rejects it for that reason, so $\mathrm{Valid}(\tau;H',\Gamma)$ follows from faithfulness while $\mathrm{Certified}(\tau;H',\Gamma,\omega')$ requires a certificate-transport or reissuance rule that produces evidence $\omega'$ indexed by the new head.

When the hypothesis fails the evidence is stale and the candidate must be revalidated or rebased. Rebasing produces a new candidate $\tau'$ against the current head, whose evidence may reuse sub-evidence for the parts whose footprints are unchanged. Certificate invalidation, revalidation, rebasing, and dependency-sensitive reuse are the four operations the chapter distinguishes, and Proposition~\ref{prop:reuse} is the condition under which reuse is sound.

\section{Commit Receipts}

A commit receipt identifies the prior authoritative head, the committed transformation, the resulting head, the evidence used, and the applicable authorization, and it carries an index of the context in which the decision was made. Authoritative history is chained by digests $d_i=\mathrm{SHA\text{-}256}(d_{i-1}\,\|\,\texttt{0x0A}\,\|\,\mathrm{canon}(e_i))$ with $d_0=\texttt{"root"}$, where $\mathrm{canon}$ is the JSON canonicalization of RFC~8785 \cite{rfc8785}.

Three properties are distinguished. \emph{Integrity} holds when the chain verifies, that is, every recorded digest equals the recomputed digest. \emph{Availability} holds when every artifact a receipt references can be retrieved. \emph{Replayability} holds when deterministic re-execution of the recorded transformations reproduces the recorded digests. Each can hold without the others. The chain also has limits as an integrity mechanism. A chain without an independently trusted head does not prevent a party from rewriting an entire history and recomputing every digest. A complete integrity model distinguishes internal chain consistency, consistency with a previously trusted head, authenticity of the party issuing a receipt, and resistance to unauthorized rewriting. The chain of this chapter establishes internal consistency and detects modification relative to retained digests, and it does not by itself establish historical authenticity.

\begin{proposition}[Integrity Detects Modification]
Assume SHA-256 collision resistance. If an event $e_i$ in a chain is altered while later digests are not recomputed, verification fails at some index $j\ge i$ except with negligible probability.
\end{proposition}

\begin{proof}
The digest $d_i$ is a function of $e_i$ and $d_{i-1}$. A modified $e_i$ with the same $d_i$ would be a collision, so $d_i$ differs, and the recorded $d_{i+1}$ was computed from the old $d_i$ and no longer matches.
\end{proof}

\begin{proposition}[Receipt Verification Is Not Claim Verification]
Verifying a receipt establishes that the recorded evidence was bound to the recorded candidate and head and that an authorization was recorded. It establishes $\mathrm{Valid}(\tau)$ at commit time only if, in addition, the checker is trusted and the profile is sound. Likewise, verifying that an authorization record is present does not verify that the authorization was legitimate, unrevoked, correctly scoped, and issued by a principal with authority to delegate it.
\end{proposition}

\begin{proof}
Receipt verification checks digests and bindings, which are properties of records. Validity is a property of the candidate, and the only link from the records to it is soundness of the profile together with trust in the checker that produced $\omega$.
\end{proof}

The distinction allows independent verification of a receipt without requiring the verifier to reproduce every internal computation, and it keeps the weaker conclusion of such verification explicit.

\chapter{Refusal Semantics}
\label{ch:refusal}

Proof-carrying refusal is developed here from a prospective extension into a semantics. A refusal record identifies the proposed continuation, the relevant context, the violated obligation, the available evidence, and, where determinable, the conditions necessary for reconsideration.

\begin{definition}[Refusal Record]
A \emph{refusal record} is $\rho=(\tau,\Gamma,o,\omega,\mathsf{rc})$ with candidate $\tau$, context $\Gamma$, obligation $o$ that is violated or unestablished, evidence $\omega$, and reconsideration conditions $\mathsf{rc}$, a predicate on later contexts.
\end{definition}

\begin{definition}[Typed Findings]
A disposition carries a set of findings from \textsf{ACCEPTABLE}, \textsf{CONTRADICTED}, \textsf{UNESTABLISHED}, \textsf{UNAUTHORIZED}, \textsf{STALE}, \textsf{DEFERRED}, and \textsf{UNRESOLVED}, with an optional primary finding. \textsf{CONTRADICTED} states that evidence shows an obligation violated, for instance a verified counterexample or a violated invariant. A checker's rejection of a submitted proof does not by itself show that the proposition is false, since it can show only that the proof is inadequate, and such a rejection is recorded as \textsf{UNESTABLISHED}. \textsf{UNESTABLISHED} states only that an obligation is not shown to hold, without claiming it fails. \textsf{UNAUTHORIZED} concerns authority, \textsf{STALE} concerns applicability of evidence to the current head, and \textsf{DEFERRED} and \textsf{UNRESOLVED} concern pending decisions.
\end{definition}

The distinction between \textsf{CONTRADICTED} and \textsf{UNESTABLISHED} carries the weight of the semantics. Absence of evidence is not evidence of a violation, and a record that conflates them would block admissible work or admit unsupported claims. A refusal is well formed only if it carries a checkable argument: for \textsf{CONTRADICTED}, evidence that a checker rejects, and for \textsf{UNESTABLISHED}, the obligation that lacks evidence.

\begin{proposition}[Deterministic Dispositions]
If the checker is deterministic, then two evaluations that agree in the candidate, the evidence record, the context index, the checker version, and every other input to adjudication return the same disposition. Evaluations of the same candidate with different evidence can differ.
\end{proposition}

\begin{proof}
The disposition is a function of the candidate, the evidence, and the context fixed by the index.
\end{proof}

Refusal then becomes constructive computational information. A recorded refusal prevents redundant attempts, since an identical proposal in an identical context is known to receive the same finding, and it guides search through the reconsideration conditions. The refusal of a repair that names no target, which the repair-target fixture of Chapter~\ref{ch:kernels} exercises, is an \textsf{UNESTABLISHED} disposition. Reconsideration is consistent with contextual admissibility (Chapter~\ref{ch:cont}): when $\mathsf{rc}$ holds in a later context the record no longer obstructs, and it remains on the ledger as history.

\chapter{Nested Spheres}
\label{ch:nested}

\section{Hierarchy}

The original calculus has one history and one world. The protocol introduces subordinate spheres, provisional transformations, and obligations imposed by a parent. A sphere is understood here as a bounded domain of admissible computational continuation and not merely as a namespace or a transaction.

\begin{definition}[Sphere]
A \emph{sphere} $s$ has a parent $p(s)$ (the authoritative history for a top-level sphere), a set of obligations $\Lambda_s$ that includes those inherited from the parent, a delegated authority $\alpha_s$ contained in that of the parent, a journal $J_s$ of provisional transformations, and a boundary certificate $W_{\partial s}$ describing what the sphere exposes to its parent. A subordinate sphere \emph{collapses into its parent} by $\mathsf{COLLAPSE}_{s\to p}$ when it is locally certified and compatible with the parent's obligations, and a top-level sphere commits to authoritative history by $\mathsf{COLLAPSE}_{s\to H}$.
\end{definition}

Associativity of composition of spheres is not assumed, and the order in which sibling spheres are collapsed may matter.

\section{Local Certification Is Not Compositional}

Model a state as a map $\sigma$ from cells to values, a transformation $\tau$ as a partial update of a set $w(\tau)$ of cells, and an obligation $O$ as a predicate on states with a \emph{read set} $R(O)$, meaning that $O(\sigma)$ depends only on $\sigma|_{R(O)}$. The transformations of this model are fixed patches $\tau_s:W_s\to V$ assigning values to a set $W_s$ of cells, and not state-dependent transformations $\tau_s:\Sigma\rightharpoonup\Sigma$, for which disjoint write sets would not suffice because one transformation could read a cell modified by another and additional read-write independence or commutativity conditions would be needed. A sphere with transformation $\tau_s$ is \emph{locally valid} if every obligation in $\Lambda_s$ holds on $\sigma_0\oplus\tau_s$, where $\sigma_0$ satisfies all obligations. It is \emph{locally certified} if in addition a checker accepts evidence for this fact; under a sound profile, local certification entails local validity, and the two are identified below only when the checker is complete for the declared obligations.

\begin{theorem}[Noncompositionality of Local Certification]
\label{thm:noncompositional}
There exist spheres $s_1,s_2$ that are each locally certified, with disjoint write sets, such that the composite $\sigma_0\oplus\tau_{s_1}\oplus\tau_{s_2}$ violates an obligation of the parent. Hence $\mathrm{Certified}(s_1)\wedge\mathrm{Certified}(s_2)$ does not imply $\mathrm{Certified}(s_1\otimes s_2)$.
\end{theorem}

\begin{proof}
Let cells be the export sets $\mathrm{exp}(A)$ and $\mathrm{exp}(B)$ of two units, both empty in $\sigma_0$, and let the parent obligation be \textsf{unique-exports}: $\mathrm{exp}(A)\cap\mathrm{exp}(B)=\varnothing$. Let $\tau_{s_1}$ add the name $\mathtt{parse}$ to $\mathrm{exp}(A)$ and $\tau_{s_2}$ add it to $\mathrm{exp}(B)$. Each of $\sigma_0\oplus\tau_{s_i}$ satisfies \textsf{unique-exports}, so both spheres are locally valid and, under a complete checker for this obligation, locally certified, and the write sets are disjoint. The composite has $\mathtt{parse}$ in both sets and violates the obligation.
\end{proof}

The nested-sphere fixture of Chapter~\ref{ch:kernels} realizes this example, and the composite is refused as \textsf{CONTRADICTED} on \textsf{unique-exports} with the head unchanged.

\begin{theorem}[Gluing Under Disjoint Interaction]
\label{thm:gluing}
Let $s_1,s_2$ be locally certified with $w(\tau_{s_1})\cap w(\tau_{s_2})=\varnothing$, and suppose that for every obligation $O$ of the parent at most one of $w(\tau_{s_1})$, $w(\tau_{s_2})$ meets $R(O)$. Then the composite satisfies every obligation of the parent.
\end{theorem}

\begin{proof}
Disjoint write sets make $\sigma_0\oplus\tau_{s_1}\oplus\tau_{s_2}$ well defined, and the updates commute. Fix an obligation $O$ with read set $R$. If neither write set meets $R$, the composite agrees with $\sigma_0$ on $R$ and $O$ holds because it holds at $\sigma_0$. If exactly one, say $w(\tau_{s_i})$, meets $R$, the composite agrees on $R$ with $\sigma_0\oplus\tau_{s_i}$, where $O$ holds by local certification of $s_i$.
\end{proof}

The hypothesis fails in the exports example, because \textsf{unique-exports} reads both cells and each sphere writes one of them. The theorem identifies the additional condition that parent-level obligations require: the interaction of spheres is mediated by the read sets of the obligations they must jointly satisfy.

\chapter{Gluing, Sites, and an Obstruction Class}
\label{ch:gluing}

\section{A Presheaf of Partial Logs}

An earlier construction took as sections over an observational region $U\subseteq\calH$ the set $U$ itself, with set inclusion as restriction. That is not a presheaf: an inclusion $V\hookrightarrow U$ gives a map from $V$ to $U$, whereas a presheaf requires a map $\mathscr F(U)\to\mathscr F(V)$ in the opposite direction. The proof of the sheaf condition also asserted that agreement on shared prefixes determines a unique reconstruction, which does not hold for partial histories: logs that cover positions $1,\dots,3$ and $5,\dots,7$ determine nothing about position $4$. The construction is replaced.

\begin{definition}[Site of Positions and Sheaf of Partial Logs]
Fix $n$ and let $X=\{1,\dots,n\}$ carry the discrete topology. For $U\subseteq X$ let $\mathscr L(U)=E^U$, the functions $U\to E$ (partial logs defined on exactly the positions in $U$), with restriction $\mathscr L(U)\to\mathscr L(V)$ for $V\subseteq U$ given by restriction of functions.
\end{definition}

\begin{proposition}[Gluing]
\label{prop:sheaf}
$\mathscr L$ is a sheaf: if $\{U_i\}$ covers $U$ and $\ell_i\in\mathscr L(U_i)$ agree on all overlaps $U_i\cap U_j$, there is a unique $\ell\in\mathscr L(U)$ with $\ell|_{U_i}=\ell_i$.
\end{proposition}

\begin{proof}
Define $\ell(p)=\ell_i(p)$ for any $i$ with $p\in U_i$, which is well defined by agreement on overlaps and total because the family covers $U$. Uniqueness holds since $\ell$ is determined at each point.
\end{proof}

This is the precise content of the engineering intuition that compatible partial logs reconstruct a single log, provided they cover it. Observation maps are not claimed to be local in this sense, and no sheaf of observable states is asserted.

\section{Cohomology on a Discrete Site Vanishes}

\begin{proposition}
On the discrete space $X$, every sheaf of abelian groups is flasque, and hence $H^k(X,\mathscr F)=0$ for $k>0$.
\end{proposition}

\begin{proof}
Sections over $U$ are the products $\prod_{p\in U}\mathscr F(\{p\})$ and restriction is projection, which is surjective, so $\mathscr F$ is flasque. Flasque sheaves are acyclic.
\end{proof}

A nontrivial obstruction theory therefore needs a topology or a nerve that encodes the interaction of computational regions, and the coefficient object and the correspondence between vanishing and solvability must be established before a cohomology group is given an interpretation. The conjecture that reachability cohomology measures the obstruction to lifting local observations to global histories remains open, and the following example shows one case in which a precisely stated obstruction class does correspond to a failed composition.

\section{A Computed Obstruction}

Three units $A,B,C$ each carry a binary polarity $x_A,x_B,x_C\in\mathbb Z/2$. Three spheres each certify a constraint on a pair: $s_{AB}$ requires $x_A+x_B=1$, $s_{BC}$ requires $x_B+x_C=1$, and $s_{CA}$ requires $x_C+x_A=1$. Each sphere is locally satisfiable, and any two compose. All three do not: adding the three equations gives $0=1$.

\begin{theorem}[Edge Constraints and $H^1$]
\label{thm:edge-h1}
Let $G$ be a finite graph and $a\in C^1(G;\mathbb Z/2)$ an assignment of a bit to each edge. The system $x_u+x_v=a_{uv}$ over the edges is solvable if and only if $a$ is a coboundary, that is, if and only if its class in $H^1(G;\mathbb Z/2)=C^1/\delta C^0$ vanishes, equivalently if and only if the sum of $a$ around every cycle is $0$.
\end{theorem}

\begin{proof}
A solution $x\in C^0$ satisfies $\delta x=a$ by the definition of the coboundary, so solvability is $a\in\delta C^0$. Since $G$ has no $2$-cells, every cochain is a cocycle and $H^1=C^1/\delta C^0$. Around a cycle $\delta x$ sums to $0$ mod $2$ because each vertex appears twice, so a coboundary sums to $0$ around every cycle; conversely, if every cycle sum vanishes, fix a spanning forest, define $x$ along it, and the non-forest edges are satisfied because each closes a cycle.
\end{proof}

For the triangle, $C^0$ has dimension $3$, $\delta$ has rank $2$ (its kernel is the constant assignments), $C^1$ has dimension $3$, so $H^1$ has dimension $1$ and the class of $a=(1,1,1)$ is detected by the cycle sum $1+1+1=1\ne0$. The class is nonzero, so the composition is impossible, and any proper subset of the three edges forms a forest, which has no cycles and so a vanishing class, which explains why any two spheres compose.

\begin{remark}
This is simplicial cohomology of the dependency graph with constant coefficients, and the correspondence between vanishing and solvability holds because the constraints are affine over a group. It is not a general identification of failures of gluing with a nonzero $H^1$. The exports example of Theorem~\ref{thm:noncompositional} is a set-theoretic clash between names and has no cocycle: no coefficient group in which the failed composition is detected by a class has been constructed, and none is claimed to exist or to be impossible. Extending the computation beyond affine constraints requires a different obstruction theory, and that extension is open.
\end{remark}

\section{Partially Ordered Histories}

The free monoid models sequential execution. Distributed computation requires distinctions among causal precedence, concurrency, serialization, and authoritative ordering. Event structures \cite{winskel} and trace monoids \cite{diekert} are the standard tools, and the relation to the present setting is as follows.

\begin{definition}[Independence and Trace Monoid]
An \emph{independence relation} is a symmetric irreflexive relation $I\subseteq E\times E$. The \emph{trace monoid} $\mathbb M(E,I)=E^*/{\equiv_I}$ is the quotient of the free monoid by the congruence generated by $ef\equiv fe$ for $(e,f)\in I$. Two linearizations represent the same causal computation iff they are equal in $\mathbb M(E,I)$.
\end{definition}

Independence is relative to what is being preserved, and observational commutativity must be distinguished from causal independence: two events can commute under an observation rule while remaining causally dependent in the computation, since Accumulate ignores distinctions that matter to authorization, evidence freshness, or resource availability. For a compositional rule $c$ let $I_c=\{(e,f)\mid e\ne f,\ [e]_c[f]_c=[f]_c[e]_c\}$.

\begin{proposition}[Equivalent Linearizations Agree]
\label{prop:linearizations}
If $c$ is compositional and $u\equiv_{I_c}v$ then $c(u)=c(v)$.
\end{proposition}

\begin{proof}
It suffices to treat a single swap $u=Kef L$, $v=Kfe L$ with $(e,f)\in I_c$. Then $[u]_c=[K]_c[e]_c[f]_c[L]_c=[K]_c[f]_c[e]_c[L]_c=[v]_c$ since $q_c$ is a homomorphism.
\end{proof}

The proposition does not establish that every observationally commuting pair can be reordered safely during execution. A protocol-level independence relation must additionally preserve legality, authorization, the obligations in force, and the promised observations.

Under $c_{\mathrm{acc}}$ every pair of distinct events is independent, because the target monoid is commutative, so all linearizations of a set of events agree. Under $c_I$ no pair is independent. For the continuation space of the original calculus, $\Pop(x)$ and $\Pop(y)$ with $x\ne y$ commute, as do $\Pop(x)$ and $\Rfuse(x,r)$ since refusal does not change the option space, yet the last pair does not commute under $c_{LW}$. A serialization chosen by the authoritative commit order is one linearization of the causal structure, and the difference between linearizations is semantically significant exactly when the pair is dependent under the guarantees the system claims to preserve.

\section{Boundary Data}

Independently processed regions communicate through constrained interfaces. The question is whether a boundary representation retains enough information to establish compatibility and discharge global obligations without exchanging the internal histories.

\begin{definition}[Sufficient Boundary]
Let $\otimes$ be a binary composition of spheres, possibly partial, and write $\widehat O(S,T)=\bot$ if $S\otimes T$ is undefined and $\widehat O(S,T)=O(S\otimes T)$ otherwise, for a predicate $O$ on composites, so that definedness of composition is part of the observed outcome. A map $\beta$ from spheres to a set $B$ is \emph{sufficient} for $O$ if $\widehat O(S,T)=g(\beta(S),\beta(T))$ for some function $g$.
\end{definition}

Define $S\approx S'$ iff for all $T$, $\widehat O(S,T)=\widehat O(S',T)$ and $\widehat O(T,S)=\widehat O(T,S')$.

\begin{theorem}[Coarsest Sufficient Boundary]
\label{thm:boundary}
The quotient map $S\mapsto[S]_\approx$ is sufficient for $O$, and every sufficient $\beta$ satisfies $\ker\beta\subseteq{\approx}$. Hence $[\cdot]_\approx$ is the coarsest sufficient boundary.
\end{theorem}

\begin{proof}
If $S\approx S'$ and $T\approx T'$ then $O(S\otimes T)=O(S'\otimes T)=O(S'\otimes T')$, using the right-hand clause for $T$ and the left-hand clause for $S$, so $O(S\otimes T)$ depends only on the classes. If $\beta$ is sufficient and $\beta(S)=\beta(S')$, then $O(S\otimes T)=g(\beta(S),\beta(T))=O(S'\otimes T)$, and likewise on the other side, so $S\approx S'$.
\end{proof}

For \textsf{unique-exports} the set of exported names is a sufficient boundary, since the obligation reads only that set. It is not sufficient for an obligation that every import be matched by an export of the right type, since that requires the types as well. The coarsest boundary is a Myhill--Nerode-style contextual equivalence for the obligation, defined here for binary interactions and not claimed to coincide with the classical syntactic congruence, which ranges over arbitrary surrounding contexts; preservation under arbitrary nested or iterated admissible contexts would be a stronger result and is not established. and what a boundary certificate $W_{\partial s}$ must contain is the information that quotient preserves. Whether a given representation attains it must be established for each obligation.

\chapter{Admissibility-Preserving Abstraction}
\label{ch:abstraction}

An abstraction $\alpha:\calH\to Z$ replaces a history by a smaller representation. A representation that preserves predictions can still fail to preserve which actions are safe, authorized, or evidentially justified, so predictive sufficiency alone is not enough for a system whose primary object is the history.

\begin{definition}[Conservative Continuation Policy]
For an abstraction $\alpha$ and $z\in\alpha(\calH)$, the \emph{conservative abstract continuation set} is $\mathrm{Cont}_{\mathrm{safe}}(z)=\bigcap_{H\in\alpha^{-1}(z)}\mathrm{Cont}(H)$.
\end{definition}

\begin{theorem}[Usability for Safe Continuation]
\label{thm:abstraction}
For every $H$, $\mathrm{Cont}_{\mathrm{safe}}(\alpha(H))\subseteq\mathrm{Cont}(H)$, so the conservative policy never proposes an inadmissible continuation. Equality holds for every $H$ if and only if $\mathrm{Cont}$ factors through $\alpha$, that is, ${\sim_\alpha}\subseteq{\sim_{\mathrm{cont}}}$. Otherwise some admissible continuation is excluded by the policy.
\end{theorem}

\begin{proof}
The inclusion holds because $H\in\alpha^{-1}(\alpha(H))$. If $\mathrm{Cont}$ is constant on each fibre, the intersection equals the common value, and conversely. The criterion for factorization is Theorem~\ref{thm:factorization}. If it fails, some fibre contains $H_1,H_2$ with different continuation sets, and then $\mathrm{Cont}_{\mathrm{safe}}\subseteq\mathrm{Cont}(H_1)\cap\mathrm{Cont}(H_2)$ is strictly smaller than one of them.
\end{proof}

Safety does not imply usefulness. The intersection can be empty or contain only the empty continuation, so the conservative policy can be safe and useless. Safety is distinct from nonblocking behavior, progress, goal reachability, and horizon viability: for a goal set $G$ an abstraction can preserve immediate admissibility while destroying the ability to choose a sequence that eventually reaches $G$, and extending the theory to these properties is a direction for future work.

The abstraction is usable for safe continuation only to the extent that the distinctions it suppresses do not invalidate the continuation guarantees. The case that separates prediction from admissibility occurs in the original calculus.

\begin{example}[Predictive but Not Admissibility-Preserving]
Let $H_1=[\Pop(x),\Rfuse(x,r)]$ and $H_2=\varepsilon$ with $\alpha=c_{LW}$. For every $K$ legal after both histories, $K$ contains no $\Pop(x)$ and $c_{LW}(H_1\hconcat K)=c_{LW}(H_2\hconcat K)$, so the abstraction has equal predictions on shared legal continuations. This is a restricted notion of predictive agreement and not predictive sufficiency over arbitrary proposed actions, since a predictor that includes blocking among its observable outcomes could distinguish the histories. Yet $[\Pop(x)]$ is admissible after $H_2$ and not after $H_1$ (Proposition~\ref{prop:cont-rules}). A policy acting on $c_{LW}$ cannot know which is the case.
\end{example}

\chapter{Admissible Forgetting and Persistent Memory}
\label{ch:forgetting}

The earlier chapters privilege retention of history. A more careful position is that a system need not retain every incidental event forever. It must retain the distinctions needed for the continuations, audits, repairs, and evidentiary obligations it claims to support. Forgetting is therefore an operation subject to admissibility constraints.

Let $R:\calH\to\mathcal R$ collect what the system promises to support: its continuation space, the answers to its audit queries, its repair targets, and its evidence obligations.

\begin{definition}[Admissible Forgetting and Destructive Forgetting]
A representation $\alpha:\calH\to Z$ is an \emph{admissible forgetting} for $R$ if $R=g\circ\alpha$ for some $g$. It is a \emph{certified abstraction} if the factorization is accompanied by a checkable argument that ${\sim_\alpha}\subseteq{\sim_R}$. Replacing a history by a representation for which no such $g$ exists is \emph{destructive}.
\end{definition}

\begin{proposition}[Composition and Minimal Size]
\label{prop:forget}
If $\alpha_1:\calH\to Z_1$ is admissible for $R$ and $\alpha_2:Z_1\to Z_2$ is admissible for the induced map $g_1$ with $R=g_1\circ\alpha_1$, then $\alpha_2\circ\alpha_1$ is admissible for $R$. Any admissible $\alpha$ satisfies $|\alpha(\calH_{\le n})|\ge|R(\calH_{\le n})|$, and the quotient $q_R$ attains equality.
\end{proposition}

\begin{proof}
Compose the factorizations: $R=g_1\circ\alpha_1=(g_2\circ\alpha_2)\circ\alpha_1$. If $R=g\circ\alpha$ then $R(\calH_{\le n})=g(\alpha(\calH_{\le n}))$, so the image of $\alpha$ is at least as large. The quotient identifies exactly the histories with equal $R$.
\end{proof}

The bound concerns the number of representational states and not minimal computational memory, encoding length under a nonuniform distribution, retrieval latency, or verification cost, and the quotient can be optimal in cardinality while expensive to compute, a distinction taken up in the next section. The proposition says how much a system must keep: no fewer states than the number of distinct promised behaviors, and that many suffice. What is promised therefore determines what may be discarded, and a stronger promise forces a finer representation.

\section{Storage and Usable Memory}

A stored history is not necessarily an accessible one. A system may retain large quantities of information while lacking the indexing, retrieval, contextualization, or computational resources to make it operationally relevant.

\begin{definition}[Usable Memory]
A stored representation $M(H)$ is \emph{usable for a question} $Q$ under budget $b$ if there is a retrieval procedure $A_Q$ with $A_Q(M(H))=Q(H)$ whose cost on every input is at most $b$.
\end{definition}

If $M$ is usable for $Q$ then $Q$ factors through $M$, so the factorization criterion is necessary. It is not sufficient, since the procedure also has to be affordable. Persistence is accordingly analyzed in relation to continuation capability and not storage capacity alone. A repository can preserve an earlier manuscript without presenting it as a current document, while its ordinary interface makes the earlier manuscript difficult to discover, so preservation of a distinction is not the same as affordable retrieval of it.

\chapter{Verification Cost and Resource-Bounded Admissibility}
\label{ch:cost}

The original calculus abstracts away the cost of verification. A continuation may be valid yet uncertifiable within the available budget. The existence of a certificate must therefore be distinguished from the feasibility of obtaining, checking, maintaining, and reproducing it.

\begin{definition}[Budgeted Admissibility]
For a budget $b=(b_{\mathrm{obtain}},b_{\mathrm{check}})$, a candidate $\tau$ is \emph{$b$-certifiable} if some evidence $\omega$ accepted by the checker can be produced within $b_{\mathrm{obtain}}$ and checked within $b_{\mathrm{check}}$. Let $\mathcal A_\Gamma^b$ be the set of histories admissible with only $b$-certifiable candidates.
\end{definition}

\begin{proposition}[Monotonicity in the Budget]
If $b\le b'$ componentwise then $\mathcal A^b_\Gamma\subseteq\mathcal A^{b'}_\Gamma\subseteq\mathcal A_\Gamma$.
\end{proposition}

\begin{proof}
A certificate within $b$ is within $b'$, and a budget restriction only removes candidates.
\end{proof}

\begin{example}[Valid but Not Certifiable]
Consider a profile whose checker accepts only exhaustive evidence for a property of a function on $n$-bit inputs, and a family of candidates $\tau_n$ that satisfy the property for every $n$. Each $\tau_n$ is valid, and certificates exist, but any accepted evidence is an explicitly enumerated record of all $2^n$ cases, so for any fixed polynomial budget the candidate is not $b$-certifiable for large $n$. The gap is a property of the profile, since a checker accepting proofs could have a smaller certificate, and this is why the choice of checker is part of the definition of the obligation.
\end{example}

Deferred verification can become unnecessary when the candidate is abandoned, superseded, or made irrelevant. What persists is the unresolved verification obligation, for as long as the corresponding guarantee remains in force, and it appears as maintenance and reproduction cost. A theory of admissibility that ignores it will overstate what can in fact be certified. The two-component budget suffices for the proposition above, and a fuller model would separate generation, verification, storage, retrieval, and maintenance budgets. This connects the abstract theory to the infrastructure on which certification runs, which Chapter~\ref{ch:infra} treats.

\section{A Partial Correspondence}
\label{sec:correspondence}

A formal correspondence between the layers can be established on a restricted instance, and the operations with no counterpart are stated.

\begin{definition}[Option-Space Instance]
Let the authoritative state be an option space $\Omega$. Take a candidate $\tau_x$ for each $x\in\Sym$ that consumes $x$, with $\mathrm{Valid}(\tau_x;H)$ iff $x\in\Omega_H$, every principal authorized, and a checker that accepts exactly the valid candidates.
\end{definition}

\begin{proposition}[Correspondence on Pop-Only Runs]
In the option-space instance, $\mathsf{commit}$ at $(H,\tau_x)$ is defined iff the base is current and $x\in\Omega_H$, and then has the effect of $\Pop(x)$ on the option space. Consequently, for a run of such commits, the authoritative history is the image of the original calculus's history under the map sending $\Pop(x)$ to $\mathsf{COLLAPSE}(\tau_x)$, restricted to the Pop events.
\end{proposition}

\begin{proof}
Valid, certified, and authorized hold iff $x\in\Omega_H$ by the choice of checker and authorization, so the definition of commit gives the stated condition. The effect on the option space is that of $\mathsf{app}(\Pop(x),\cdot)$ by construction.
\end{proof}

The correspondence is partial. Refusal in the original calculus appends an event to the history, while in the protocol a refusal is recorded in the ledger and the authoritative history is unchanged. The original Bind and Collapse events, a dependency and an observation, have no authoritative counterpart: in the protocol an observation is a derived, read-only function and not an event. The protocol's POP, TRANSFORM, and VERIFY act on journals and evidence and have no counterpart in the original calculus. Histories of the original calculus that contain refusals are therefore not histories of the protocol, and the two calculi coincide only on the Pop-only fragment above.

\chapter{Generators, Authors, and Responsibility}
\label{ch:agency}

Language models enter the protocol as components that generate candidate transformations within spheres. A model's capacity to generate a plausible continuation does not establish that the continuation is admissible, that its supporting evidence is adequate, or that the model holds authority to commit it. The protocol can therefore be understood as an architecture for using generative systems without conflating generation, verification, and authorization, which are separate roles filled by separate checks (Chapter~\ref{ch:vca}).

\section{Provenance and Accountability}

Five notions are distinguished: causal participation in producing a transformation, generation provenance (which component produced it), editorial responsibility, certification responsibility, and accountable authorship. A historical record can identify which component produced a transformation without establishing that the component is an accountable author. Provenance is a fact about causes, while accountability is a relation between an agent and consequences that requires, at least, the capacity to answer for them and a standing to be held to account. The distinction applies equally to automatic commit attribution, to institutional claims about mathematical results, and to software that assigns credit without a corresponding assignment of responsibility.

\section{Software Degradation}

A succession of locally successful patches can produce a globally degraded codebase through duplication, architectural fragmentation, unmaintained dependencies, and growing verification cost \cite{sdlt}. A development architecture can impose obligations on architectural preservation, deletion, reuse, simplification, and the coherence of interfaces.

\begin{proposition}[Tests Establish Declared Obligations and Their Consequences]
Under a sound profile whose declared obligations are those exercised by a test suite $\mathcal T$, acceptance by $\mathcal T$ establishes the declared obligations together with their logical consequences. It does not in general establish an obligation that is not entailed by them.
\end{proposition}

\begin{proof}
Soundness is relative to the declared obligations, and an obligation entailed by them holds whenever they do: a checker establishing that a quantity equals $2k$ establishes that it is even, though parity is not separately declared. An obligation not entailed by the declared ones, such as a bound on duplication, is not an input to the checker. There exist test suites and patches for which copying a function preserves every tested behavior while violating a duplication bound.
\end{proof}

Passing tests therefore do not constitute sufficient evidence that a transformation preserves the desired architecture. Architectural obligations must be declared with their own checkers.

\chapter{Revision Histories as Training Data}
\label{ch:revision}

The thesis that a history carries information a snapshot does not has a direct application to the construction of corpora for learning systems. A corpus assembled from the final state of a repository presents each statement as a standing assertion. A corpus assembled from the revision history presents the same statements together with the order in which they were introduced, qualified, demoted, and withdrawn, and so exposes the process of correction that produced the final state. This chapter states that difference precisely, using the observation machinery of Part~\ref{part:pop-calc} through Part~\ref{part:cont}, and records what the available literature does and does not show.

\section{Snapshots as Observations}

Let $H$ be a selected linear ancestry of a repository, regarded as a sequence of commits, and let $\mathrm{snap}(H)$ be the file tree at its head. Git histories in general are directed acyclic graphs, in which branches diverge, merge, abandon alternative formulations, and maintain versions concurrently. This chapter restricts itself to a selected linear ancestry, and a graph-based definition of supersession, which would connect to the distributed-history chapter, is left open. The map $\mathrm{snap}$ is an observation in the sense of Chapter~\ref{ch:quotient}: it assigns to each history a value in a smaller space, and it identifies histories with the same final tree. A snapshot corpus is the image of a family of repositories under this map.

\begin{proposition}[Snapshots Do Not Determine Supersession]
\label{prop:snapshot}
There are histories $H_1,H_2$ with $\mathrm{snap}(H_1)=\mathrm{snap}(H_2)$ such that a statement $s$ is withdrawn in $H_1$ and never asserted in $H_2$. Consequently there is no function of the snapshot that is correct on the unrestricted family of histories for the property that a statement was withdrawn, and in particular none for the former position of an author.
\end{proposition}

\begin{proof}
Let $H_2$ consist of one commit adding a manuscript $M$ that does not contain $s$. Let $H_1$ consist of a commit adding $M\cup\{s\}$ followed by a commit removing $s$. The final trees are equal, and the property ``$s$ was asserted and later withdrawn'' holds for $H_1$ and fails for $H_2$.
\end{proof}

The proposition does not show that no particular snapshot can reveal supersession: a final manuscript can document its earlier formulations, and a repository can contain an edition history. The result is that snapshots alone support no universally correct reconstruction.

The same argument applies to a drafts directory. If an obsolete manuscript and its revision are both present in the final tree, a snapshot contains two documents and no relation between them, and a pipeline that ingests the tree treats each as independently endorsed. Filenames, dates, metadata, and accompanying documentation can encode a relation between versions, but a directory of versions does not itself establish their semantic relationships. If the revision is made in place, the history contains the relation, since the later version replaces the earlier one at the same path, but only a pipeline that reads the history can use it. The relation is recoverable from the history and is not recoverable from the snapshot, which is an instance of Theorem~\ref{thm:nonfactor}.

\section{Supersession and Position}

A history induces a status for each statement at each revision, and the status function can be defined directly from the events.

\begin{definition}[Local and Retrospective Status]
For a history $H=[e_1,\dots,e_n]$ of revisions, a statement $s$, and a position $k\le n$, the \emph{local status} $S_{\mathrm{local}}(s,k)$ is \emph{present} if $s$ occurs in the tree after $e_k$ and \emph{absent} otherwise; it is ascertainable at revision $k$. The \emph{retrospective status} $S_{\mathrm{retro}}(s,k;n)$ classifies an occurrence of $s$ at $k$ using the revisions through $n$: \emph{standing} if $s$ occurs after every later revision, \emph{superseded} if it is replaced at a later position by a statement recorded as its revision, and \emph{withdrawn} if it is removed at a later position without replacement. The retrospective statuses are mutually exclusive for an occurrence that is not standing.
\end{definition}

Using retrospective status to label an example intended to represent an earlier epistemic state would leak later information into it, so training examples for revision at position $k$ must use $S_{\mathrm{local}}$ and the context available at $k$, with $S_{\mathrm{retro}}$ reserved for evaluation and for assessment. These are textual statuses. A statement's presence in a document does not establish that the author endorses it, since a manuscript can contain quotations, objections, hypothetical arguments, rejected conjectures, and claims attributed to others, and its removal does not establish that the author rejects it. The textual status can often be reconstructed mechanically from the history, while the epistemic status, namely what the author held, requires semantic interpretation and further evidence. A former position of an author is therefore a claim about epistemic status that textual status supports only defeasibly. Whether a replacement is recorded as a revision of the replaced statement, and not an unrelated addition, depends on the repository and the parsing procedure, and no general procedure is claimed.

\section{Learning Transformations}

Ordinary language-model training estimates a distribution over documents, $P(D)$. A revision-oriented objective estimates a conditional distribution over transformations,
\[
P(\Delta D\mid D,H,C),
\]
where $D$ is the current document, $H$ is its revision history, and $C$ is the context for the proposed revision, which in a repository may include the commit message, the associated tests, the changes to related files, and the dependency changes. In the terms of this monograph a transformation $\Delta D$ is a proposed continuation, and the conditional distribution is a proposal generator of the kind discussed in Chapter~\ref{ch:agency}. Repositories can supply richer context than most other sources of edits, because commits carry explanations and are often accompanied by tests and by changes to other files.

Prior work on the revision histories of Wikipedia indicates what such supervision can contain. An early study compared adjacent versions of articles to extract training data for lexical error correction and sentence compression \cite{nelken}. A later corpus of corrections and paraphrases separated meaning-preserving from meaning-altering revisions \cite{max}. A corpus of 43 million atomic insertions and deletions across eight languages was reported to support the claim that models trained on edits encode different aspects of semantics and discourse than models trained on ordinary text \cite{faruqui}. A dataset of about 21 million revisions across 32 thousand articles was used to train a model that predicts the quality of an edit from its content \cite{sarkar}. These works establish that revision pairs are a usable source of supervision for local textual transformation and for judging edits. They do not establish that training on repository histories teaches the revision of mathematical arguments, such as the demotion of a theorem to a conjecture or the addition of a missing hypothesis, and this is a hypothesis for investigation and not a result.

\section{Revisions Are Not Automatically Improvements}

A later revision need not be an improvement. A commit can introduce an error, reverse a correct change, or reflect a preference with no epistemic content, and a history in which every revision is treated as a positive example would teach the reproduction of the author's habits together with the author's corrections. In the vocabulary of Chapter~\ref{ch:vca}, a revision is a proposed continuation that has been committed, and in the protocol of this monograph its commitment establishes authorization and not validity. Ordinary Git does not enforce the protocol's authorization requirements: it can contain unauthorized commits, forged author metadata, mistakenly accepted changes, and changes made with compromised credentials, so a commit establishes inclusion in a recorded history and authorization is a separate question. The quality-prediction work cited above addresses part of this problem for Wikipedia by learning to assess edits \cite{sarkar}. A history-based corpus therefore needs a layer of assessment: evidence that a revision removed an error, for example a later test that passes or a proof that is checked, should determine whether the revision is used as a positive example, a negative example, or is excluded. Persistence is a weak behavioral signal and not a certificate: an error can persist because nobody notices it, and an incorrect change can survive because its consequences are expensive to investigate. A corpus should therefore distinguish independently verified correction, editorial acceptance, persistence, and unresolved epistemic status.

A second limitation concerns what a revision history records. A commit history records the continuations that were accepted. The proposals that were drafted and discarded before commitment, and the refusals that preceded a change, are in the terms of Chapter~\ref{ch:separation} part of the ledger and not of the authoritative history, and a version-control history does not ordinarily contain them. The abandoned proofs, for example, are largely absent unless the author committed them before abandoning them. The supervision available from commits is therefore supervision for the sequence of accepted corrections, which is informative about what was accepted and uninformative about why alternatives were rejected, except where commit messages or review records state it.

\section{Status}

The proposition above is proved, and it is a statement about observation and not about any training procedure. The claims about learning are hypotheses, and they are separated here because they differ in what they would show. The first concerns historical reconstruction and tests whether a model benefits from access to historical information. The second concerns corrective transfer, and the third evidentiary discrimination, and these are the more consequential because they concern transferable capabilities and not reconstruction of recorded history.

\begin{conjecture}[Historical Reconstruction]
For a family of repositories whose revisions contain demotions, added hypotheses, and withdrawn definitions, a model trained on the revision sequences with an assessment layer outperforms a model trained on the final snapshots of the same repositories at predicting, for a held-out statement, whether it is standing, superseded, or withdrawn.
\end{conjecture}

\begin{conjecture}[Corrective Transfer]
Revision-oriented training improves the identification and repair of previously unseen defects in mathematical or technical arguments.
\end{conjecture}

\begin{conjecture}[Evidentiary Discrimination]
Training on assessed revisions improves the distinction between genuine corrections, unsupported alterations, and stylistic modifications.
\end{conjecture}

An experimental comparison would need to control for training-token budgets, repeated exposure to nearly identical documents, repository-level separation of training and test data, model architecture, and chronological leakage. The literature relevant to a fuller programme also includes software-edit prediction, automated program repair, learning from code-review histories, temporal knowledge editing, and models trained to generate patches, and the bibliographic details of the works cited here should be verified before the bibliography is finalized.

\chapter{Institutional and Infrastructural Admissibility}
\label{ch:infra}

A continuation may be theoretically realizable while depending on infrastructure controlled by an external institution that can revoke access, alter terms, or impose prohibitive costs. Whether an agent retains the resources to undertake a continuation independently is a question about the context $\Gamma$ and not about the history.

\begin{proposition}[Admissibility Can Change Without a Change of History]
There are contexts $\Gamma_t,\Gamma_{t'}$ with the same authoritative history $H$ and a continuation $K$ such that $K\in\mathrm{Cont}_{\Gamma_t}(H)$ and $K\notin\mathrm{Cont}_{\Gamma_{t'}}(H)$.
\end{proposition}

\begin{proof}
Let $K$ require a resource $r$ controlled by a third party, with admissibility conditioned on access to $r$. If access is available in $\Gamma_t$ and revoked in $\Gamma_{t'}$ then the claim follows, since neither context changes $H$.
\end{proof}

The proposition shows that admissibility evolution depends on the environment as well as on the record, and that a purely history-based account is incomplete for resource-bounded agency. The relevant structure includes the distinction between resources an agent owns and resources it leases, the revocability of each dependence, and the cost of replacing a dependence. A formal authorization can persist while the practical capability to realize the transformation is lost, so authorization and capability are distinct predicates, which supports representing admissibility through several predicates and not a single scalar. This belongs to a theory of resource-bounded computational agency and not to the core operational semantics, and it extends the history-primary framework to the conditions under which computational continuations remain practically available.

\chapter{Open Problems and Future Directions}
\label{ch:future}

\section{Resource-Indexed Types}

The type system does not track the option space, and Theorem~\ref{thm:progress} is accordingly qualified. A judgement $\Gamma;\Omega\vdash t:T\dashv\Omega'$ in which Pop consumes an affine resource would exclude blocked evaluation statically. Whether such a system remains syntax-directed, and what becomes of the open and closed world modes, are open.

\section{Metatheory of the Lambda Fragment}

Preservation, progress, and history equality for the lambda fragment require a reduction relation with closures and capture-avoiding substitution, together with canonical forms and substitution lemmas. None is established here.

\section{Interpretation and Observation}

An earlier statement of an adjunction between a functor constructing histories from terms and the observation functor was not substantiated: the category of terms was not defined and the proposed bijection mentioned an inverse of the interpreter that does not exist in general. Whether the interpreter, regarded as a map from terms to histories, has a left or right adjoint on a defined category of terms is open. A related question is whether Church--Rosser can be recovered by an observation that is compositional, computable from the retained events alone, and defined beyond normalizing executions (Chapter~\ref{ch:lambda}).

\section{Fibres and Obstruction Classes}

A general characterization of the fibres of a collapse rule, and of the subclasses of histories on which a rule is injective, is open (Chapter~\ref{ch:topology}). Beyond affine constraints, an obstruction theory for compositional failures needs a coefficient object, a topology on regions, and a proved correspondence between vanishing of a class and solvability (Chapter~\ref{ch:gluing}). The conjectural reachability cohomology is not defined by this monograph.

\begin{conjecture}[Reachability Cohomology]
There is a topology on a site of computational regions and a coefficient object for which a class in the first cohomology group vanishes exactly when local observations that agree on overlaps extend to a global history, for a nontrivial family of collapse rules.
\end{conjecture}

\section{Graded and Structured Admissibility}

The profiles of Chapter~\ref{ch:structured} need not be numerical. Whether their value sets carry a useful lattice structure, whether profiles compose along nested spheres, and which components are determined by the others are open. The relation to graded admissibility fields in the RSVP program is a direction and not a result.

\section{Distributed Runtimes}

A distributed runtime coordinates several worlds under a consistency constraint that must be expressed through equivalence of histories under a shared rule and not through equality of values. Conflict-free replicated data types \cite{shapiro} provide partial models, with merge operations on records. The additional structure here is the typed refusal record and the commit rule, and it is open how these interact with convergence guarantees.

\section{Proof-Carrying Refusal}

Chapter~\ref{ch:refusal} makes a refusal carry a checkable argument. The complexity of checking such arguments, and the conditions under which \textsf{UNESTABLISHED} dispositions can be turned into \textsf{CONTRADICTED} ones by further evidence, are not treated.

\section{Protocol Conformance}

Conformance of an implementation to the full protocol, including journals, rebasing, authorization time, and the receipt context index, is open, and the ledger of Chapter~\ref{ch:kernels} lists the gaps.

\chapter{Conclusion}
\label{ch:conclusion}

The original thesis of this monograph was that computation is the progressive restriction of possibility and not the manipulation of values. For the finite-option calculus of Parts~\ref{part:pop-calc} through~\ref{part:cont} that is an accurate description, and Theorem~\ref{thm:conservation} is its precise form. The results since have shown its limits as a general account. Computation can generate possibilities by refinement, decomposition, repair, delegation, and changes in resources. It can fail to compose even when every part is locally admissible. It can discard history without loss when the representation preserves what is promised, and it can discard history with loss when it does not.

A broader thesis follows from these results, and it is offered as a thesis and not as a theorem. Historical accountability is not a feature of every computation in the ordinary mathematical sense, since a conventional computation can occur without retaining any accountable history, so the thesis is an organizing principle for a history-primary architecture and a proposed semantics of accountable computation, and not a characterization of computation in general: computation is the historically accountable transformation of admissible continuation spaces. Contraction is then a special case and not a universal law. Repair is a continuation and does not erase history. Abstraction is admissible when it preserves what is promised and is otherwise destructive. Composition requires conditions on interfaces. Generation does not confer authority. The question of interest is no longer only what happened, or what observable state a history produces, but what a history permits, which distinctions must survive for later computation to remain admissible, and what evidence justifies admitting a proposed continuation into the authoritative record.

What this monograph establishes is limited. The core fragment has a proved type preservation, a progress theorem qualified by availability, and a proved equality of interpreter and compiled histories. Observation is characterized as a quotient with proved results on compositionality, factorization, and limits, and the relation of observation to continuation is stated and proved on the original calculus. The certification architecture, nested spheres, boundary data, abstraction, and forgetting are developed as definitions with propositions proved on explicit models. The protocol is exercised by two reference kernels and three fixtures, with the gaps recorded. The lambda fragment, the adjunctions, and a general obstruction theory are open, and Appendix~\ref{app:ledger} records the status of each result.

\section{Evidential Status of Tests}

The tests below are evidence and not proofs. Each passing test checks the relevant result for the specific terms it uses and does not show that the result holds for every program of the language. \subsection*{Bookkeeping (Theorem~\ref{thm:conservation})}
\begin{lstlisting}
#[test]
fn world_history_grows_option_space_shrinks() {
    let mut w = World::new(OptionSpace::new([
        Symbol::new("a"), Symbol::new("b"),
    ]));
    let initial = w.options.len();
    w.pop(Symbol::new("a")).unwrap();
    // |H| increased by 1; |Omega| decreased by 1
    assert_eq!(w.history.len(), 1);
    assert_eq!(w.options.len(), initial - 1);
    // Refuse does NOT shrink option space
    w.refuse(Symbol::new("b"),
             RefusalReason::NotAvailable);
    assert_eq!(w.options.len(), initial - 1); // unchanged
    assert_eq!(w.history.len(), 2);           // history grew
}
\end{lstlisting}

The test checks that Pop shrinks the option space, that Refuse does not, and that the history grows in both cases.

\subsection*{Refinement (Proposition~\ref{prop:disambiguation})}
\begin{lstlisting}
#[test]
fn finer_rule_disambiguates_equivalent_histories() {
    // Two histories equivalent under Accumulate
    // but distinct under Identity
    let mut w1 = World::new(OptionSpace::new([
        Symbol::new("x"), Symbol::new("y"),
    ]));
    w1.pop(Symbol::new("x")).unwrap();
    w1.pop(Symbol::new("y")).unwrap();

    let mut w2 = World::new(OptionSpace::new([
        Symbol::new("x"), Symbol::new("y"),
    ]));
    w2.pop(Symbol::new("y")).unwrap();
    w2.pop(Symbol::new("x")).unwrap();

    // Under Accumulate: both map to {x:1, y:1} -- equivalent
    let obs1_acc = w1.observe(&CollapseRule::Accumulate);
    let obs2_acc = w2.observe(&CollapseRule::Accumulate);
    assert_eq!(obs1_acc.entries, obs2_acc.entries,
        "accumulate should not distinguish pop order");

    // Under Identity: histories differ in event order
    assert_ne!(w1.history, w2.history,
        "identity rule distinguishes pop order");
}
\end{lstlisting}

Accumulate places the two histories in one class and Identity, which is finer, separates them. The No Direct Observation result (Theorem~\ref{thm:no-direct-obs}) is a cardinality fact and is not tested; the refinement test above exhibits a concrete pair of distinct histories that a coarse rule identifies.
