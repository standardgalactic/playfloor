\section{Key Definitions}

\begin{description}
\item[Fiber.] $\pi^{-1}(m) = \{x \in \mathcal{X} : \pi(x) = m\}$. The set of all alternative histories consistent with compressed state $m$. Counterfactual reasoning is navigation within fibers.

\item[Query-flat fiber.] A fiber in which all elements produce approximately the same query answers: $\sup_{x,x' \in \pi^{-1}(m)} |Q(x) - Q(x')| \leq \varepsilon$. The geometric consequence of stability.

\item[Cone of recoverability.] $C_\varepsilon(x_0,\pi,\mathcal{Q}) = \{x : |Q(x) - \pi^+_Q(\pi(x))| \leq \varepsilon\}$. Broad under exponential stability; narrow under polynomial; collapsed under no stability.

\item[Aligned compression.] A compression whose equivalence classes coincide with the directions the stability sequence renders negligible. Collapses stable directions; preserves important directions. Eliminates all architectural failure modes.

\item[Type I degeneracy.] Compression collapses trajectories the query family distinguishes. Information destroyed. Examples: false memories, revisionism.

\item[Type II degeneracy.] Formal sufficiency ($\varepsilon_1 = 0$) but ill-conditioned reconstruction. Examples: accessibility skeleton on continuous spaces, dark-sector parameter degeneracy.
\end{description}

\section{Framework Summary: Eight Steps}

\begin{enumerate}
  \item Define the trajectory space $\mathcal{X}$ and reference $x_0$.
  \item Define the interaction decomposition: specify $I_r^{Q,x_0}$ and verify exactness.
  \item Verify stability: bound $|I_r^{Q,x_0}| \leq C_Q \sigma_r$ and check $\sum_{r>d} \sigma_r \to 0$.
  \item Define the compression $\pi$ and depth $d_\pi$; identify the fiber structure.
  \item Verify sufficiency: compute or bound $\varepsilon_1$.
  \item Bound approximation error $\varepsilon_0$.
  \item Check alignment: $d_\pi = d_Q$; all three error terms share the same decay rate.
  \item Diagnose failure modes: which of the five failure types is active?
\end{enumerate}
